
## Сортировка по выражению

В `ORDER BY` можно указывать не только готовые колонки, но и выражения.

Например, есть таблица `posts` с лайками и просмотрами:

|id|title|likes|views|
|--:|---|--:|--:|
|1|SQL Basics|50|1000|
|2|Window Functions|80|400|
|3|Joins Explained|120|3000|

Можно отсортировать посты не просто по лайкам, а по доле лайков от просмотров:

```sql
SELECT title, likes, views
FROM posts
ORDER BY likes * 1.0 / views DESC;
```

В таблице нет отдельной колонки с таким показателем. База посчитает выражение на лету и отсортирует результат по нему.

Здесь `1.0` помогает получить дробное деление, а не целочисленное.

Ещё пример — сортировка по длине имени:

```sql
SELECT name
FROM users
ORDER BY LENGTH(name) DESC;
```

Сначала будут пользователи с самыми длинными именами.
