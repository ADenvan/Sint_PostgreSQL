
## Пример: последние заказы

Допустим, нужно показать 5 последних заказов.

```sql
SELECT id, customer_id, amount, created_at
FROM orders
ORDER BY created_at DESC, id DESC
LIMIT 5;
```

Почему здесь два поля в сортировке?

`created_at DESC` ставит свежие заказы выше старых.  
`id DESC` помогает, если несколько заказов созданы в одну и ту же секунду.

Такой запрос подходит для реального интерфейса: порядок будет понятным и стабильным.
