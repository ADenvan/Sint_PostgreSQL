
## ORDER BY и UNION

Если ты объединяешь результаты через `UNION`, сортировку обычно пишут один раз в самом конце.

Например:

```sql
SELECT name, email
FROM customers
UNION
SELECT name, email
FROM partners
ORDER BY name;
```

Здесь `ORDER BY name` сортирует общий результат после объединения.

Не нужно ставить отдельный `ORDER BY` в каждую часть запроса, если тебе нужен итоговый порядок всей выдачи.

Правильная мысль такая: сначала собрать общий список, потом отсортировать его.
