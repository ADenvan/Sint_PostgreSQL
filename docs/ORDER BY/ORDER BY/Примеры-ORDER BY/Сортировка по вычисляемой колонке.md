
## Сортировка по вычисляемой колонке

Часто выражение удобно вывести в `SELECT`, дать ему понятное имя и потом сортировать по этому имени.

Например:

```sql
SELECT
  title,
  likes,
  views,
  likes * 1.0 / views AS engagement_rate
FROM posts
ORDER BY engagement_rate DESC;
```

Так запрос читается легче:

- в `SELECT` мы считаем показатель;
- в `ORDER BY` сортируем по нему.

Это особенно удобно в отчётах, где есть расчётные метрики: конверсия, средний чек, CTR, доля от общего числа и так далее.
