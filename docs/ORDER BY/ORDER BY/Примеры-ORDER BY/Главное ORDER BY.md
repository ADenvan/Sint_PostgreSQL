
## Главное ORDER BY

`ORDER BY` нужен, чтобы задать понятный и предсказуемый порядок строк в результате запроса.

Без него база не гарантирует порядок. Даже если тебе кажется, что строки «и так идут нормально», это случайность, а не правило.

## Главные шаблоны:

```sql
SELECT title, price
FROM products
ORDER BY price;
```

```sql
SELECT title, price
FROM products
ORDER BY price DESC;
```

```sql
SELECT name, department, salary
FROM employees
ORDER BY department ASC, salary DESC;
```

```sql
SELECT title, created_at
FROM posts
ORDER BY created_at DESC, id DESC
LIMIT 10;
```

Запомни:

- `ASC` — по возрастанию;
- `DESC` — по убыванию;
- `ASC` можно не писать, он используется по умолчанию;
- несколько колонок в `ORDER BY` дают многоуровневую сортировку;
- `ORDER BY` вместе с `LIMIT` позволяет делать топы и последние записи;
- для стабильного порядка добавляй уникальную колонку, например `id`;
- с `NULL` и строковыми числами нужно быть особенно внимательным.

`ORDER BY` — это не украшение запроса, а способ превратить набор строк в понятный список. Именно с него начинается нормальная выдача: товары становятся отсортированными, отчёты — читаемыми, ленты — свежими, а топы — честными.
