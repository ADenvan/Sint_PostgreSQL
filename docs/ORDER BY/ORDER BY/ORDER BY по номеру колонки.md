
## ORDER BY по номеру колонки

SQL позволяет сортировать по номеру колонки из `SELECT`.

Например:

```sql
SELECT title, rating
FROM books
ORDER BY 2 DESC;
```

`2` означает вторую колонку в результате, то есть `rating`.

Запрос сработает. Но для учебного и рабочего кода это не лучший стиль.

Почему?

Потому что такой запрос хуже читается. Нужно глазами считать, какая колонка в `SELECT` первая, какая вторая. А если кто-то поменяет порядок колонок, сортировка может случайно измениться.

Лучше писать явно:

```sql
SELECT title, rating
FROM books
ORDER BY rating DESC;
```

Так понятнее и тебе, и человеку, который будет читать запрос после тебя.
