
### Сортировать текстовые числа как настоящие числа

Если колонка строковая, сортировка будет строковой:

```sql
SELECT title, price_text
FROM products
ORDER BY price_text;
```

Если данные уже такие, можно привести тип:

```sql
SELECT title, price_text
FROM products
ORDER BY CAST(price_text AS INTEGER);
```

Но правильнее хранить цену в числовой колонке.
