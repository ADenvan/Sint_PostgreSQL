
### Не добавить второй критерий при одинаковых значениях

Плохо:

```sql
SELECT id, title, rating
FROM books
ORDER BY rating DESC;
```

Если у нескольких книг одинаковый рейтинг, порядок между ними не гарантирован.

Лучше:

```sql
SELECT id, title, rating
FROM books
ORDER BY rating DESC, id ASC;
```

Теперь сортировка стабильнее.
