
[[Думать, что порядок есть сам по себе]] - что база вернёт строки в порядке добавления.
- Может показаться, что посты будут идти по `id`. Но SQL этого не обещает.
[[Использовать LIMIT без ORDER BY]] - Так ты получишь просто 10 строк. Не топ, не последние, не первые по смыслу.
[[Забыть направление сортировки]] - Если написать просто `ORDER BY created_at`, база отсортирует по возрастанию. То есть сначала будут самые старые даты.
[[Не добавить второй критерий при одинаковых значениях]] - Если у нескольких книг одинаковый рейтинг, порядок между ними не гарантирован.
