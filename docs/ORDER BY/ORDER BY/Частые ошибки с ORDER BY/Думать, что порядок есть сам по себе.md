
### Думать, что порядок есть сам по себе

Самая частая ошибка: считать, что база вернёт строки в порядке добавления.

Например:

```sql
SELECT id, title
FROM posts;
```

Может показаться, что посты будут идти по `id`. Но SQL этого не обещает.

Нужен порядок по `id` — напиши явно:

```sql
SELECT id, title
FROM posts
ORDER BY id;
```

Нужны свежие посты — тоже явно:

```sql
SELECT id, title, created_at
FROM posts
ORDER BY created_at DESC, id DESC;
```
