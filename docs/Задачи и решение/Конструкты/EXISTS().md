
**Что это:** Логический оператор с подзапросом. Возвращает `TRUE`, если подзапрос возвращает хотя бы одну строку, и `FALSE`, если не возвращает ничего. _Важно:_ ему не важны сами значения в подзапросе, только факт наличия строк (поэтому внутри часто пишут `SELECT 1`). **Где применяется:** WHERE, HAVING. _Ограничение:_ это не функция, а оператор подзапроса, его нельзя использовать в SELECT или GROUP BY напрямую как обычное выражение. **Пример:**

```sql
SELECT name FROM departments
WHERE EXISTS (SELECT 1 FROM employees WHERE employees.dept_id = departments.id);
```

**Простыми словами:** Проверяет, есть ли вообще какие-то данные по условию. В примере выводит названия только тех отделов, в которых есть хотя бы один сотрудник. Работает быстрее, чем `IN`, если таблица `employees` огромная.
