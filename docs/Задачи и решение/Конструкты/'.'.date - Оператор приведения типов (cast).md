
### ::

**Что это:** Оператор приведения типов (cast) в стиле PostgreSQL. Это более короткая альтернатива стандартному `CAST(x AS type)`. 
**Где применяется:** Везде, где нужно изменить тип данных: SELECT, WHERE, JOIN, INSERT. **Пример:**

```sql
SELECT '2026-10-30'::date;
```



**Простыми словами:** Преобразует один тип данных в другой. В примере текст `'2026-10-30'` принудительно превращается в тип `date`.

---
```sql
SELECT o.last_name, o.product, p.price, c.category 
FROM orders o 
JOIN prices p ON o.product = p.product 
JOIN categories c ON p.price <@ c.price_range::numrange;
```
- [[Категория цены без CASE и IF Оператор]] - 
	- **`c.price_range::numrange`**:  _"Преобразуй эту строку в настоящий математический числовой диапазон"_.

-  [[Дневные обороты по банковским продуктам]] - В PostgreSQL столбец `amount_rub` имеет тип `MONEY`. `AVG()` с ним не работает вовсе, а `SUM()` возвращает `money` — со знаком валюты и разделителями разрядов.
```sql
SELECT product_code, op_ts::date AS txn_day, 
	COUNT(*) AS txn_cnt, 
	SUM(amount_rub::numeric) AS total_amount,
```
