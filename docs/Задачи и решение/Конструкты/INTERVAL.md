
**Что это:** Тип данных и ключевое слово для задания временного интервала (периода времени: дни, часы, месяцы и т.д.). 
**Где применяется:** SELECT, WHERE, JOIN (в условиях). Чаще всего используется в арифметике с датами (прибавить/отнять период от даты). **Пример:**

```sql
SELECT CURRENT_DATE + INTERVAL '7 days';
```

**Простыми словами:** Позволяет работать с периодами времени. В примере к сегодняшней дате прибавляется ровно 7 дней.
