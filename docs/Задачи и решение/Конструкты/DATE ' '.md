
**Что это:** Литерал (строковый синтаксис) для явного создания значения типа `date`. _Уточнение:_ внутри кавычек не должно быть пробелов, формат строго `'YYYY-MM-DD'`. 
**Где применяется:** SELECT, WHERE, INSERT, UPDATE. Используется там, где нужно жестко задать дату на уровне парсера SQL, избегая неявных преобразований. **Пример:**

```sql
SELECT * FROM users WHERE birth_date = DATE '1990-05-15';
```
**Простыми словами:** Превращает текст в полноценную дату. В примере ищет пользователей, родившихся 15 мая 1990 года, гарантируя, что база воспримет это именно как дату, а не как строку.
