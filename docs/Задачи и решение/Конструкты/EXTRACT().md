
**Что это:** Функция для извлечения отдельных частей (полей) из даты или времени: год, месяц, день, час, день недели (DOW) и т.д. Всегда возвращает число (тип `double precision`). 
**Где применяется:** SELECT, WHERE, GROUP BY, ORDER BY. **Пример:**

```sql
SELECT EXTRACT(YEAR FROM CURRENT_DATE);
```

**Простыми словами:** Вытаскивает нужную цифру из даты. В примере достает текущий год (2026) из сегодняшней даты.
