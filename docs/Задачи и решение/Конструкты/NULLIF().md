
**Что это:** Функция, возвращающая `NULL`, если два переданных аргумента равны. Если они не равны, возвращает первый аргумент. Аргументы должны быть одного типа. **Где применяется:** SELECT, WHERE, HAVING. Чаще всего используется в арифметике для защиты от ошибок. **Пример:**

```sql
SELECT total_sales / NULLIF(num_orders, 0) AS avg_sales FROM stats;
```

**Простыми словами:** Превращает конкретное значение в `NULL`, если оно совпадает со вторым аргументом. В примере, если `num_orders` равно 0, функция вернет `NULL`. Деление на `NULL` даст `NULL`, и запрос не упадет с ошибкой "division by zero".
