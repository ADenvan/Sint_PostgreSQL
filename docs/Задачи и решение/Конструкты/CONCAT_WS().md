
**Что это:** Функция для склеивания строк с разделителем (Concatenate With Separator). Первый аргумент — это разделитель, все последующие — строки для склеивания. _Важно:_ она автоматически пропускает `NULL`-значения. **Где применяется:** SELECT, WHERE (при сравнении строк), INSERT, UPDATE. **Пример:**

```sql
SELECT CONCAT_WS(', ', 'Иван', NULL, 'Иванов');
```

**Простыми словами:** Собирает текст из кусков, разделяя их заданным символом. В примере склеит 'Иван' и 'Иванов' через запятую и пробел, полностью проигнорировав `NULL` (результат: `'Иван, Иванов'`, без лишних запятых на месте пропуска).
