 
**Что это:** Системное ключевое слово, возвращающее текущую дату (без времени) в часовом поязе сервера БД. 
**Где применяется:** SELECT, WHERE, FROM, JOIN и т.д. _Ограничение:_ возвращает тип `date`, поэтому его нельзя напрямую сравнивать с `timestamp` без явного приведения типов. **Пример:**

```sql
SELECT * FROM orders WHERE order_date = CURRENT_DATE;
```

**Простыми словами:** Показывает сегодняшнюю дату по часам сервера. В примере фильтрует только те заказы, которые были созданы сегодня.
