
**Что это:** Литерал (строковый синтаксис) для явного создания значения типа `timestamp` (дата и время без часового пояса). _Уточнение:_ формат внутри кавычек должен быть стандартным ISO (обычно `'YYYY-MM-DD HH:MM:SS'`). Если нужен часовой пояс, используется `TIMESTAMPTZ ' '`. 

**Где применяется:** SELECT, WHERE, INSERT, UPDATE. Используется для жесткой передачи даты и времени на уровне парсера SQL. **Пример:**
```sql
SELECT * FROM logs WHERE created_at > TIMESTAMP '2026-11-05 10:00:00';
```
**Простыми словами:** Превращает текст в полноценную дату со временем. В примере ищет записи в логах, созданные строго после 10 утра сегодняшнего дня (5 ноября 2026 года).
