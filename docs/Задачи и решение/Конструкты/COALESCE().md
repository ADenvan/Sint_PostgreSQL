
**Что это:** Функция, которая возвращает первый аргумент из списка, не равный `NULL`. Все аргументы должны быть совместимы по типу данных (или неявно приводиться к одному). **Где применяется:** SELECT, WHERE, HAVING, ORDER BY, GROUP BY. Ограничений по месту нет, но типы аргументов должны совпадать. **Пример:**

```sql
SELECT COALESCE(nickname, username, 'Аноним') AS display_name FROM users;
```

**Простыми словами:** Заменяет `NULL` на нужное значение. Идет по списку слева направо и берет первое непустое. В примере: если у пользователя нет `nickname`, возьмет `username`; если и его нет — подставит текст 'Аноним'.
