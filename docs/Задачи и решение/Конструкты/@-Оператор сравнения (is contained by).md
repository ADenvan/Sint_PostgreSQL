
# <@
**Что это:** Оператор сравнения, означающий "полностью содержится внутри" (contained by). _Условие:_ Работает **только** со специфичными типами данных PostgreSQL: массивами, диапазонами (`int4range`, `tsrange`, `daterange` и т.д.) и геометрическими типами. С обычными числами или датами не работает. 
**Где применяется:** WHERE, HAVING, SELECT (в логических выражениях). **Пример:** 

```sql
SELECT * FROM events WHERE event_date <@ daterange('2026-10-01', '2026-11-01');
```

**Простыми словами:** Проверяет, находится ли левый элемент целиком внутри правого. В примере выбирает события, дата которых попадает в диапазон октября 2026 года.
