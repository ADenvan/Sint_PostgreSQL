
На собеседовании в Avito проверяют, понимает ли кандидат, что `DISTINCT` поверх результата группировки часто ничего не меняет. На данных из таблицы `events` нужно определить, сколько строк вернёт запрос:

SELECT DISTINCT a, b, c, SUM(d) AS revenue
FROM events
GROUP BY a, b, c

Оберните этот запрос и верните количество строк в одной колонке `rows_returned`.

```sql
SELECT COUNT(*) AS rows_returned
FROM (
    SELECT DISTINCT a, b, c, SUM(d) AS revenue
    FROM events
    GROUP BY a, b, c
) AS subquery;
```
1. **`AS subquery` (ОЧЕНЬ ВАЖНО!):** В PostgreSQL **обязательно** нужно давать имя (алиас) любой таблице или подзапросу в блоке `FROM`. Если ты забудешь написать `AS subquery` (или любое другое слово, например `AS t`), база выдаст ошибку: `subquery in FROM must have an alias`.

### 💡 Pro-совет от дата-аналитика:

Такой прием (подзапрос в `FROM`) называется **Derived Table** (производная таблица). Это один из самых мощных инструментов аналитика. Он позволяет решать задачи в несколько этапов:

1. Сначала сформировать нужные данные (сгруппировать, отфильтровать, посчитать).
2. А потом сделать с этим результатом еще одно действие (посчитать строки, найти среднее от средних и т.д.).
### 🛠 Что значит «обернуть запрос»?

Представь, что внутренний запрос создает невидимую временную таблицу с результатами. Твоя задача — написать внешний запрос, который просто посчитает количество строк (`COUNT(*)`) в этой временной таблице.
