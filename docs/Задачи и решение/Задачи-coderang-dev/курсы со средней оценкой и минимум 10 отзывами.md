
Возьмите только опубликованные курсы (`is_published = TRUE`). 
Для курсов, у которых есть не менее 10 оценок, посчитайте среднюю оценку и округлите её до двух знаков после запятой. 
Архивные курсы в результат не включайте.


```sql
SELECT 
    c.course_name, 
    ROUND(AVG(r.rating), 2) AS avg_rating
FROM courses c
JOIN ratings r ON c.course_id = r.course_id
WHERE c.is_published = TRUE
GROUP BY c.course_id, c.course_name
HAVING COUNT(r.rating) >= 10;
```
### 🧠 Разбор по шагам (почему это работает):

1. **`WHERE c.is_published = TRUE`** — сразу отсекаем архивные и неопубликованные курсы. Они даже не попадут в группировку, что экономит ресурсы базы.
2. **`GROUP BY c.course_id, c.course_name`** — _Pro-совет:_ всегда добавляй первичный ключ (`course_id`) в `GROUP BY`, если он есть. Если вдруг появятся два курса с одинаковым названием `course_name`, база не склеит их в один, а посчитает корректно.
3. **`ROUND(AVG(r.rating), 2)`** — база сначала считает среднее арифметическое всех оценок в группе, а затем округляет результат до 2 знаков после запятой (например, `4.555...` превратится в `4.56`).
4. **`HAVING COUNT(r.rating) >= 10`** — это фильтр **после** группировки. Он говорит: _"Оставь в финальном результате только те группы (курсы), где количество строк с оценками больше или равно 10"_.
