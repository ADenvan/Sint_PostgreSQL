
## Активные студенты на 15 апреля 2024 года


У каждой записи на курс есть период доступа `enrollment_period` типа `DATERANGE`: дата начала включается, дата окончания не включается. 
Посчитайте, сколько уникальных студентов на дату `2024-04-15` имели хотя бы один активный период доступа.  

Если у студента несколько активных курсов, считайте его только один раз.
^a4
```sql
SELECT COUNT(DISTINCT user_id) AS active_users
FROM user_courses
WHERE enrollment_period @> DATE '2024-04-15'
```

^9fb24e
