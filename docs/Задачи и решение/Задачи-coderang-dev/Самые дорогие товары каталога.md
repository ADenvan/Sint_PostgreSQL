Вот задача:
Дизайнер главной страницы хочет показать карточку «премиум-товар» — товар с самой высокой ценой в каталоге. Если несколько товаров стоят одинаково дорого и делят первое место, покажите их всех. Верните `id`, название и цену товара. Отсортируйте результат по `id`.

```sql
SELECT id, name, price
FROM products
WHERE price = (SELECT MAX(price) FROM products)
GROUP BY id, name
```
### 🧠 Разбор по шагам:

1. **`(SELECT MAX(price) FROM products)`** — это **подзапрос**. База сначала выполняет его и получает одно число: `12000.00`.
2. **`WHERE price = 12000.00`** — теперь внешний запрос фильтрует таблицу, оставляя только строки, где цена равна этому числу.
3. **`ORDER BY id`** — сортируем результат по `id`, как требует задание.
### 💡 Pro-совет от дата-аналитика: продвинутый вариант через оконные функции

В реальных рабочих задачах аналитики часто используют **оконные функции**, особенно когда нужно решить похожую задачу, но с дополнительными условиями (например, "топ-1 товар в каждой категории"). Вот как это выглядит:
```sql
SELECT id, name, price
FROM (
    SELECT 
        id, 
        name, 
        price,
        RANK() OVER (ORDER BY price DESC) AS rnk
    FROM products
) AS ranked
WHERE rnk = 1
ORDER BY id;
```
**Как это работает:**
- `RANK() OVER (ORDER BY price DESC)` присваивает каждой строке "место" в рейтинге по убыванию цены.
- Если у двух товаров одинаковая цена, они получают **одинаковый ранг** (оба `rnk = 1`).
- Затем во внешнем запросе мы оставляем только `rnk = 1`.
