
Здесь нужно проверить работу с соединением таблиц, группировкой и фильтрацией групп. Найдите произведения, у которых вышло больше пяти изданий, и для каждого такого произведения верните общее число изданий.

```sql
SELECT 
    w.work_id, 
    w.title, 
    COUNT(e.edition_id) AS edition_count
FROM work w
JOIN edition e ON w.work_id = e.work_id
GROUP BY w.work_id, w.title
HAVING COUNT(e.edition_id) > 5
ORDER BY w.work_id DESC;
```
