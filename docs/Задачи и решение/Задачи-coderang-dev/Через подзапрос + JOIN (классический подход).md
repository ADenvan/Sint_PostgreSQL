
## Самый доступный товар в каждой категории

Маркетинг запускает акцию «начни знакомство с категорией с самого доступного товара». 
Для каждой категории найдите товар или товары с минимальной ценой внутри этой категории. 
Верните `id`, название, категорию и цену таких товаров. 
Отсортируйте результат по категории.
Нам нужно найти минимальную цену **не по всей таблице**, а **отдельно для каждой категории**.
- В категории `books` — свой минимум (450.00)
- В категории `home` — свой минимум (350.00)
- В категории `sport` — свой минимум (990.00)
^j1
```sql
SELECT p.id, p.name, p.category, p.price
FROM products p
JOIN (
    SELECT category, MIN(price) AS min_price
    FROM products
    GROUP BY category
) AS min_prices 
ON p.category = min_prices.category 
AND p.price = min_prices.min_price
ORDER BY p.category;
```

^bfe594

2. **JOIN:** Мы соединяем исходную таблицу `products` с этой временной таблицей по **двум условиям одновременно**:
    - `p.category = min_prices.category` — та же категория
    - `p.price = min_prices.min_price` — цена равна минимуму в этой категории
3. **`ORDER BY p.category`** — сортируем по категории, как требует задание.
### Через оконную функцию (элегантный подход)
```sql
SELECT id, name, category, price
FROM (
    SELECT 
        id, 
        name, 
        category, 
        price,
        RANK() OVER (PARTITION BY category ORDER BY price) AS rnk
    FROM products
) AS ranked
WHERE rnk = 1
ORDER BY category;
```
### 🧠 Как это работает:
1. **`RANK() OVER (PARTITION BY category ORDER BY price)`**
    - `PARTITION BY category` — делит таблицу на "окна" по категориям (каждая категория — отдельное окно)
    - `ORDER BY price` — внутри каждого окна сортирует товары по цене
    - `RANK()` — присваивает место (ранг) каждому товару в его категории
    - Товары с одинаковой минимальной ценой получают **одинаковый ранг = 1**
2. **`WHERE rnk = 1`** — оставляем только товары, которые заняли первое место в своей категории (то есть имеют минимальную цену).
