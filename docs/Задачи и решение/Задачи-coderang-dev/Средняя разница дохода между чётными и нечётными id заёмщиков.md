Вот задача:
Аналитик Sravni.ru проверяет, насколько сбалансирована выгрузка заёмщиков по чётным и нечётным id — такой разрез часто используют как быстрый A/B-контроль. 
Посчитайте, насколько средний доход семьи (`profit_family`) у заёмщиков с чётным `id` выше, чем у заёмщиков с нечётным `id`. 
Верните одно число, округлённое до двух знаков. 
Если средний доход у нечётных id выше, результат должен получиться отрицательным сам по себе, без модуля.
### 🛠 Ключевые инструменты:

- **`id % 2 = 0`** — оператор `%` (остаток от деления). Если `id` делится на 2 без остатка → чётный.
- **`AVG(...) FILTER (WHERE ...)`** — супер-фишка PostgreSQL! Позволяет посчитать среднее **только для строк, удовлетворяющих условию**, не разделяя таблицу на две через `GROUP BY`.
^f1
```sql
SELECT ROUND(
    AVG(profit_family) FILTER (WHERE id % 2 = 0) - 
    AVG(profit_family) FILTER (WHERE id % 2 = 1), 
    2
) AS fam_diff
FROM borrowers;
```

### Альтернативный вариант (через подзапросы):
```sql
SELECT ROUND(
    (SELECT AVG(profit_family) FROM borrowers WHERE id % 2 = 0) -
    (SELECT AVG(profit_family) FROM borrowers WHERE id % 2 = 1),
    2
) AS fam_diff;
```
### 🧠 Разбор по шагам:

1. **`AVG(profit_family) FILTER (WHERE id % 2 = 0)`** База смотрит на все строки, но для среднего берёт **только те**, где `id` чётный. Получается среднее по Группе А.
2. **`AVG(profit_family) FILTER (WHERE id % 2 = 1)`** То же самое, но для нечётных `id`. Получается среднее по Группе Б.
3. **`... - ...`** Просто вычитаем одно среднее из другого.
4. **`ROUND(..., 2)`** Округляем итоговое число до двух знаков после запятой.
