
## Самый доступный товар в каждой категории

НЕ могу понять как решить эту задачу.
Вот задача:
Маркетинг запускает акцию «начни знакомство с категорией с самого доступного товара». Для каждой категории найдите товар или товары с минимальной ценой внутри этой категории. Верните `id`, название, категорию и цену таких товаров. Отсортируйте результат по категории.

```sql
SELECT id, name, price
FROM products
WHERE price = (SELECT MAX(price) FROM products)
ORDER BY id;
```
### 🧠 Разбор по шагам:
1. **`(SELECT MAX(price) FROM products)`** — это **подзапрос**. База сначала выполняет его и получает одно число: `12000.00`.
2. **`WHERE price = 12000.00`** — теперь внешний запрос фильтрует таблицу, оставляя только строки, где цена равна этому числу.
3. **`ORDER BY id`** — сортируем результат по `id`, как требует задание.
### продвинутый вариант через оконные функции
```sql
SELECT id, name, price
FROM (
    SELECT 
        id, 
        name, 
        price,
        RANK() OVER (ORDER BY price DESC) AS rnk
    FROM products
) AS ranked
WHERE rnk = 1
ORDER BY id;
```
