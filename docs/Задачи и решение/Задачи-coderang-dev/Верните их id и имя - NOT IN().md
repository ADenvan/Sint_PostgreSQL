
Маркетинг готовит промокод для «спящих» клиентов — тех, кто зарегистрировался, но за всё время так и не оформил ни одного заказа, даже отменённого. 
Найдите таких клиентов и верните их `id` и имя. 
Отсортируйте результат по `id`.
^n1
```sql
SELECT c.id, c.name
FROM customers c
WHERE c.id NOT IN (SELECT o.customer_id FROM orders o)
```
