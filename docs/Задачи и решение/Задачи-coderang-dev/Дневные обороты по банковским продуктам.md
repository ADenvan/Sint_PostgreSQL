
Каждая операция привязана к клиенту, категории продукта и сумме в рублях. 
Сверните данные до уровня «продукт + день»: посчитайте количество операций, суммарный оборот и среднюю сумму операции. 
Среднюю сумму округлите до двух знаков. 
В PostgreSQL столбец `amount_rub` имеет тип `MONEY`. `AVG()` с ним не работает вовсе, а `SUM()` возвращает `money` — со знаком валюты и разделителями разрядов. 
Приведите значения к `numeric` (`amount_rub::numeric`), чтобы `total_amount` и `avg_amount` вернулись числами. В ClickHouse столбец уже `Decimal`, там приведение не нужно.

```sql
SELECT product_code, op_ts::date AS txn_day,
  COUNT(*) AS txn_cnt,
  SUM(amount_rub::numeric) AS total_amount,
  ROUND(AVG(amount_rub::numeric), 2) AS avg_amount
FROM bank_operations
GROUP BY product_code, txn_day
ORDER BY product_code, txn_day ASC
```
