
Операционному аналитику нужно увидеть города, где сеть уже выросла до стратегически значимого масштаба. 
Для каждого города посчитайте число работающих складов, где `is_open = TRUE`, и оставьте только города, где таких складов строго больше `80`. 
Самые крупные города должны быть вверху результата. 
Отсортируйте результат по `warehouse_count` (по убыванию).

```sql
SELECT city, COUNT(warehouse_id) AS warehouse_count
FROM warehouses
WHERE is_open = TRUE
GROUP BY city
HAVING COUNT(warehouse_id) > 80
ORDER BY warehouse_count DESC
```

### 🧠 Разбор по шагам (почему это работает):

1. **`WHERE is_open = TRUE`** Мы сначала отсекаем все закрытые склады. Важно делать это _до_ группировки, чтобы не считать их в общую массу.
2. **`GROUP BY city`** Мы говорим базе: "Собери все строки в кучки по названию города".
3. **`COUNT(warehouse_id) AS warehouse_count`** Внутри каждой "кучки" (города) мы считаем количество уникальных идентификаторов складов.
4. **`HAVING COUNT(warehouse_id) > 80`** Это **ключевой момент**. `WHERE` фильтрует _отдельные строки_, а `HAVING` фильтрует _результаты агрегации_ (группы). Нам нужно отбросить целые города, если сумма складов в них ≤ 80. Поэтому используем именно `HAVING`.
5. **`ORDER BY warehouse_count DESC`** Сортируем итоговую таблицу по посчитанному количеству по убыванию (от большего к меньшему).
