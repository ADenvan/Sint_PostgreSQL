

В Росбанке слой DDS хранит историю контрактов как SCD2: каждая версия записи действует в интервале `valid`, открытом справа. 
Аналитику нужен срез состояния контрактов на дату `2024-03-15`. 
Для каждого контракта верните ту версию, чей интервал `valid` содержит эту дату. Контракты без активной версии на эту дату в результат не включайте. 
Для `dt_to` верните верхнюю границу интервала `valid`, а если правая граница бесконечная — верните `NULL`.

^a3
```sql
SELECT contract_id, status, rate_pct,
  lower(valid) AS dt_from,
  CASE
    WHEN upper_inf(valid) THEN NULL
    ELSE upper(valid)
  END AS dt_to
FROM contracts_history
WHERE valid @> DATE '2024-03-15'
```

^a6115c

## 🧠 Разбор по шагам:

### 1. **Фильтрация по дате: `valid @> DATE '2024-03-15'`**

Оператор `@>` читается как **"содержит"**. Он проверяет, попадает ли дата `2024-03-15` внутрь диапазона `valid`.
Примеры:
- `[2024-02-01,2024-04-01)` содержит `2024-03-15` → **TRUE** ✓
- `[2024-04-01,)` содержит `2024-03-15` → **FALSE** ✗
- `[2024-01-15,)` содержит `2024-03-15` → **TRUE** ✓

### 2. **Извлечение границ диапазона**
**`lower(valid)`** — возвращает нижнюю (левую) границу диапазона:
- Из `[2024-02-01,2024-04-01)` → `2024-02-01`
- Из `[2024-01-15,)` → `2024-01-15`

**`upper(valid)`** — возвращает верхнюю (правую) границу:
- Из `[2024-02-01,2024-04-01)` → `2024-04-01`
- Из `[2024-01-15,)` → **ошибка!** (граница бесконечна)

### 3. **Обработка бесконечности: `upper_inf(valid)`**
Функция `upper_inf()` проверяет, **бесконечна ли верхняя граница**:
- `[2024-02-01,2024-04-01)` → `upper_inf()` = **FALSE**
- `[2024-01-15,)` → `upper_inf()` = **TRUE**

Поэтому мы используем `CASE`: если граница бесконечна, возвращаем `NULL`, иначе — обычную дату.

## 💡 Полезные функции для работы с диапазонами:

|Функция|Что делает|Пример|
|---|---|---|
|`lower(range)`|Нижняя граница|`lower('[1,5)')` → `1`|
|`upper(range)`|Верхняя граница|`upper('[1,5)')` → `5`|
|`lower_inf(range)`|Нижняя граница бесконечна?|`lower_inf('(,5)')` → `TRUE`|
|`upper_inf(range)`|Верхняя граница бесконечна?|`upper_inf('[1,)')` → `TRUE`|
|`isempty(range)`|Диапазон пустой?|`isempty('[1,1)')` → `TRUE`|
|`range @> value`|Содержит значение?|`'[1,5)' @> 3` → `TRUE`|
