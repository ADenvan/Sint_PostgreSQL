
Команда локализации выбирает страну, где у сервиса больше всего клиентов: именно туда пойдёт первая волна перевода интерфейса и маркетинговых материалов. Найдите страну с максимальным числом клиентов и выведите всех клиентов из неё. Верните `id`, имя и страну клиента. Отсортируйте результат по `id`.
^w1
```sql
SELECT id, name, country
FROM customers
WHERE country = (
    SELECT country
    FROM customers
    GROUP BY country
    ORDER BY COUNT(*) DESC
    LIMIT 1
)
ORDER BY id;
```

^d0a7b9

### 🧠 Разбор по шагам:
1. **Внутренний запрос (в скобках):**
    - `GROUP BY country` — группирует клиентов по странам
    - `ORDER BY COUNT(*) DESC` — сортирует группы по количеству клиентов (от большего к меньшему)
    - `LIMIT 1` — берёт только первую строку (страну с максимумом клиентов)
    - Возвращает одно значение: `'RU'`
2. **Внешний запрос:**
    - `WHERE country = 'RU'` — фильтрует клиентов только из этой страны
    - `ORDER BY id` — сортирует результат по `id`, как требует задание
3. **`GROUP BY` во внешнем запросе НЕ НУЖЕН** — мы же просто выводим всех клиентов из одной страны, а не считаем что-то.

**оконную функцию**
```sql
SELECT id, name, country
FROM (
    SELECT 
        id, 
        name, 
        country,
        COUNT(*) OVER (PARTITION BY country) AS country_cnt,
        MAX(COUNT(*)) OVER () AS max_cnt
    FROM customers
) AS t
WHERE country_cnt = max_cnt
ORDER BY id;
```
