
Бухгалтер закрывает квартал и готовит выгрузку заказов только по российским клиентам — это нужно для отчёта по РФ-юрлицу. 
Найдите заказы клиентов, у которых страна равна `RU`. 
Верните `id` заказа, `customer_id` и сумму заказа. Отсортируйте результат по `id` заказа.

Требование к решению
Это задача на проверку наличия: решение должно использовать `IN` с подзапросом или `EXISTS`. Соединение таблиц даёт тот же ответ, но решает другую задачу и не засчитывается.

```sql
SELECT o.id, o.customer_id, o.total
FROM orders o
WHERE o.customer_id IN (SELECT id FROM customers WHERE country = 'RU')
ORDER BY o.id
```

```sql
SELECT o.id, o.customer_id, o.total
FROM orders o
WHERE EXISTS (SELECT 1 FROM customers c WHERE c.id = o.customer_id AND c.country = 'RU')
ORDER BY o.id
```
