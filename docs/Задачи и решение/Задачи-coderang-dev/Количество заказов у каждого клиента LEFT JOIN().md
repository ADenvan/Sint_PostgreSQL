
## Количество заказов у каждого клиента

Помоги решить задачу. я запутался.
Вот Задача:
Саппорт хочет видеть рядом с каждым клиентом счётчик заказов, чтобы сразу отличать постоянных покупателей от тех, кто только зарегистрировался. Для каждого клиента посчитайте общее количество его заказов любого статуса. Клиенты без заказов тоже должны попасть в результат со значением `0`. Верните `id`, имя клиента и счётчик в колонке `orders_count`. Отсортируйте результат по `id` клиента.

Вот мое ре не полное решение:
```sql
SELECT 
    c.id, 
    c.name, 
    COUNT(o.customer_id) AS orders_count
FROM customers c
LEFT JOIN orders o ON c.id = o.customer_id
GROUP BY c.id, c.name
ORDER BY c.id;
```
### 🧠 Разбор по шагам:
1. **`LEFT JOIN orders o ON c.id = o.customer_id`** База берет всех клиентов из `customers` (включая Мишу с id=7). Для Миши нет заказов, поэтому все поля из `orders` для него становятся `NULL`.
2. **`COUNT(o.customer_id)`** — это **очень важный момент**!
    - Функция `COUNT(колонка)` считает **только НЕ-NULL значения**.
    - Для Миши `o.customer_id` будет `NULL`, поэтому `COUNT` вернет `0`. ✓
    - ⚠️ Если бы ты написал `COUNT(*)`, база посчитала бы саму строку (даже пустую), и у Миши получилось бы `1` — это была бы ошибка!
3. **`GROUP BY c.id, c.name`** По строгому стандарту SQL все колонки из `SELECT`, которые не обернуты в агрегатную функцию, должны быть в `GROUP BY`. Я добавил `c.name`.
4. **`ORDER BY c.id`** Сортируем по `id`, как требует задание.
