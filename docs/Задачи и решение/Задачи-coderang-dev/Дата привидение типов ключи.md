
Посчитайте средний возраст клиентов, которые в 2024 году купили товар с `name = 'Smartwatch'`. Округлите результат до одного знака после запятой.
```sql
SELECT ROUND(AVG(age), 1) AS average_age
FROM purchases
JOIN customers on purchases.customer_id = customers.customer_id
JOIN products on purchases.product_id = products.product_id
WHERE purchased_at::date >= DATE '2024-01-01' 
	AND purchased_at::date <= DATE '2024-12-31' 
	AND name = 'Smartwatch'
```
**Не используй `::date` на колонке в WHERE, если можно этого избежать:** Когда ты пишешь `purchased_at::date`, ты заставляешь базу применять функцию к каждой строке перед проверкой, что может замедлить запрос на больших данных. Лучше сравнивать исходный `timestamp` с `timestamp` (как во Варианте 2).
```sql
SELECT ROUND(AVG(age), 1) AS average_age
FROM purchases
JOIN customers ON purchases.customer_id = customers.customer_id
JOIN products ON purchases.product_id = products.product_id
WHERE purchased_at >= DATE '2024-01-01' 
  AND purchased_at < DATE '2025-01-01'
  AND products.name = 'Smartwatch';
```
## Альтернативные способы фильтрации по году
**Вариант 1 (через EXTRACT)**
Функция `EXTRACT` позволяет вытащить из даты конкретную часть (в данном случае год).
^d2
```sql
WHERE EXTRACT(YEAR FROM purchased_at) = 2024
  AND name = 'Smartwatch'
```

**Вариант 2 (через DATE_TRUNC)**

WHERE DATE_TRUNC('year', purchased_at) = DATE '2024-01-01'
  AND name = 'Smartwatch'
