

Здесь нам на помощь придет супер-функция аналитика — **`CONCAT_WS()`** (Concat With Separator). Её фишка в том, что она **автоматически игнорирует значения `NULL`** и не ставит между ними разделитель.
^d1
```sql
SELECT 
    CONCAT_WS(' - ', last_nm, first_nm, NULLIF(middle_nm, '')) AS fio,
    birth_dt
FROM employees
WHERE is_active = true
ORDER BY last_nm ASC;
```

^923f75

Но есть один нюанс: `CONCAT_WS` игнорирует только `NULL`. Если в базе в поле `middle_nm` лежит не `NULL`, а **пустая строка** `''`, функция всё равно добавит лишний дефис. Чтобы это исправить, мы используем функцию **`NULLIF()`**, которая превращает пустую строку в `NULL`.
1. **`CONCAT_WS(' - ', ...)`** — говорит базе: _"Склеивай следующие значения, разделяя их строкой `' - '` (дефис с пробелами, как в твоем примере)"_.
2. **`NULLIF(middle_nm, '')`** — говорит: _"Проверь отчество. Если оно равно пустой строке `''`, верни `NULL`"_.
3. **Как это работает вместе:**
    - Для _Belov Igor Aleksandrovich_: `CONCAT_WS` склеивает все три слова -> `Belov - Igor - Aleksandrovich`.
    - Для _Black John_ (где отчество пустое): `NULLIF` превращает пустоту в `NULL`. `CONCAT_WS` видит `NULL`, игнорирует его и **не ставит** лишний дефис в конце -> `Black - John`.
