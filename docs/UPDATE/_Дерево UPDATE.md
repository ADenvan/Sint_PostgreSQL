
# Что такое UPDATE в SQL?

UPDATE — это команда «поменять данные в существующих строках». Простыми словами: что меняем, как обязательно сужать WHERE, как поменять сразу несколько колонок. Таблицы before/after, типичные ловушки новичков, мини-резюме и три задачки на закрепление.

`UPDATE` — это команда, которая **изменяет данные в уже существующих строках**.

Не добавляет новые строки — для этого есть `INSERT`.  
Не удаляет строки — для этого есть `DELETE`.  
А именно **исправляет то, что уже лежит в таблице**.

Представь таблицу как блокнот с контактами.  
`INSERT` — это добавить нового человека.  
`DELETE` — вычеркнуть человека из блокнота.  
А `UPDATE` — аккуратно заменить старый номер телефона на новый, потому что человек переехал или сменил SIM-карту.

В SQL это одна из самых важных команд. И одновременно одна из тех, с которыми нужно быть особенно внимательным: `UPDATE` действительно меняет данные.
