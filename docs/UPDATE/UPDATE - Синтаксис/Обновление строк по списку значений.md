
## Обновление строк по списку значений

Иногда нужно обновить несколько конкретных строк.

Например, перевести несколько заказов в статус `cancelled`.
```sql
UPDATE orders
SET status = 'cancelled'
WHERE id IN (101, 102, 103);
```
`IN` удобен, когда есть список конкретных значений.

То же самое можно было бы написать через несколько `OR`, но получилось бы длиннее:
```sql
UPDATE orders
SET status = 'cancelled'
WHERE id = 101 OR id = 102 OR id = 103;
```

Для новичка `IN` обычно читается проще: обнови строки, где `id` входит в этот список.
