
## UPDATE внутри транзакции - `BEGIN` и `COMMIT`

Если база поддерживает транзакции, опасные обновления лучше делать внутри `BEGIN` и `COMMIT`.
```sql
BEGIN;

UPDATE users
SET tier = 'gold'
WHERE email = 'anya@example.com';

COMMIT;
```
Смысл транзакции простой: ты открываешь «режим черновика», выполняешь изменение, проверяешь результат и только потом окончательно сохраняешь.

Если что-то пошло не так, можно сделать откат:
```sql
BEGIN;

UPDATE users
SET tier = 'gold'
WHERE email = 'anya@example.com';

ROLLBACK;
```
`ROLLBACK` отменит изменения внутри текущей транзакции.

В PostgreSQL после `UPDATE` обычно видно, сколько строк обновилось. Например:
```text
UPDATE 1
```
Это значит: обновлена одна строка.

Если ты ожидал одну строку, а увидел:
```text
UPDATE 247
```
лучше остановиться и разобраться. Возможно, условие оказалось слишком широким.
