
## UPDATE меняет данные, но не структуру таблицы

Важно не путать:
`UPDATE` меняет значения в строках.
Он не создаёт новые колонки, не удаляет старые и не меняет типы данных.

Например, такой запрос меняет значение:
```sql
UPDATE users
SET name = 'Anna'
WHERE id = 1;
```

А если нужно добавить новую колонку, это уже не `UPDATE`, а `ALTER TABLE`.

```sql
ALTER TABLE users
ADD COLUMN middle_name TEXT;
```

Простая разница:

|Команда|Что делает|
|---|---|
|`UPDATE`|Меняет данные в строках|
|`INSERT`|Добавляет новые строки|
|`DELETE`|Удаляет строки|
|`ALTER TABLE`|Меняет структуру таблицы|

## UPDATE и ограничения таблицы

База данных не даст записать что угодно, если на таблице есть ограничения.
Например, если колонка `email` не может быть пустой, такой запрос может упасть:
```sql
UPDATE users
SET email = NULL
WHERE id = 1;
```

Если на колонке `price` стоит проверка, что цена должна быть больше нуля, такой запрос тоже может не пройти:

```sql
UPDATE products
SET price = -100
WHERE id = 10;
```
Это хорошо. Ограничения защищают таблицу от плохих данных.

`UPDATE` пытается изменить строку, но база всё равно проверяет правила: типы данных, `NOT NULL`, уникальность, внешние ключи, `CHECK`-ограничения.
