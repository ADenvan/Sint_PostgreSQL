
## Мини-резюме - `UPDATE`

`UPDATE` — команда для изменения данных в уже существующих строках.
Она не добавляет строки и не удаляет их, а меняет значения в выбранных колонках.

Главные части запроса:
- `UPDATE` — какую таблицу обновляем;
- `SET` — какие колонки меняем;
- `WHERE` — какие строки попадают под обновление.

Самое важное правило: **не забывай WHERE**. Без него обновятся все строки таблицы.
Перед важным обновлением сначала сделай `SELECT` с тем же условием. Так ты увидишь, какие строки будут затронуты.

Если меняешь деньги, баллы, остатки товаров или любые счётчики, лучше считать новое значение прямо в SQL:
```sql
UPDATE users
SET points = points + 5
WHERE id = 1;
```
Так база обновит текущее значение аккуратно и за одну операцию.

`UPDATE` — мощная команда. Она делает ровно то, что ты написал. Поэтому хороший SQL-разработчик пишет обновления спокойно, внимательно и всегда проверяет условие.
