
## SET: что именно меняем

Часть `SET` отвечает за новые значения.

Например:
```sql
UPDATE products
SET price = 1200
WHERE id = 10;
```
Здесь мы говорим: у товара с `id = 10` поставить цену `1200`.

Можно менять строку:
```sql
UPDATE orders
SET status = 'paid'
WHERE id = 500;
```

Можно менять дату:
```sql
UPDATE posts
SET published_at = NOW()
WHERE id = 7;
```

Можно менять логическое значение:
```sql
UPDATE users
SET is_verified = TRUE
WHERE id = 1;
```
`SET` — это место, где ты описываешь новую версию данных.

## Можно обновить несколько колонок сразу

В одном `UPDATE` можно изменить не одну колонку, а сразу несколько.

Например, пользователь купил платный тариф, и мы хотим:
- изменить тариф;
- записать дату обновления;
- отметить, что пользователь подтверждён.

```sql
UPDATE users
SET
  tier = 'gold',
  upgraded_at = NOW(),
  is_verified = TRUE
WHERE id = 1;
```

Обрати внимание на запятые между присваиваниями.

Такой запрос выполняет все изменения вместе. Это лучше, чем делать три отдельных `UPDATE`, потому что данные не окажутся в странном промежуточном состоянии.

Например, не будет ситуации, где тариф уже `gold`, а дата обновления ещё пустая. База применяет изменение как одну операцию.
