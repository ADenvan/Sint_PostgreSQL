
## UPDATE с проверкой результата

Для денежных операций, остатков товаров и бонусов часто важно понять: обновилась строка или нет.

Например:
^u1
```sql
UPDATE accounts
SET balance = balance - 30
WHERE id = 1 AND balance >= 30
RETURNING id, balance;
```

^54a144

Если строка вернулась — списание прошло.
Если строка не вернулась — либо счёта нет, либо денег недостаточно.
Такой подход часто надёжнее, чем сначала делать отдельный `SELECT`, а потом отдельный `UPDATE`.
