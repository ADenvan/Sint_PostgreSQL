
## RETURNING: сразу увидеть, что изменилось

В PostgreSQL у `UPDATE` есть очень удобная возможность — `RETURNING`.

Она позволяет сразу вернуть обновлённые строки.
```sql
UPDATE users
SET tier = 'gold'
WHERE id = 1
RETURNING id, name, tier;
```
Так ты не только обновляешь данные, но и сразу видишь результат.

Это особенно удобно, когда:
- нужно проверить, что обновилась правильная строка;
- приложение должно получить новое значение;
- ты хочешь увидеть итог без отдельного `SELECT`.

Например:
```sql
UPDATE orders
SET status = 'paid'
WHERE id = 500
RETURNING id, status, updated_at;
```
Для обучения это очень приятная команда: она помогает видеть результат прямо после изменения.
