
**Агрегация в SQL** — это процесс преобразования множества детальных строк из таблицы в одно сводное значение с помощью специальных функций. Проще говоря, она «сжимает» набор данных в одну метрику: сумму, среднее, количество элементов, минимум или максимум.

**Агрегация** — это общий процесс объединения разрозненных данных в компактные сводные метрики, удобные для анализа. Например, вы можете взять список всех заказов и провести агрегацию, чтобы узнать общее количество заказов, сумму продаж по всем товарам или среднее количество товаров в заказе.

---
[[_Дерево Агрегатные функции COUNT, SUM, AVG, MIN, MAX]] - **Ограничения на место применения.** Агрегатные функции нельзя использовать в предложении `WHERE` - только в `SELECT` или `HAVING`. Это важное правило, которое часто становится источником ошибок.
