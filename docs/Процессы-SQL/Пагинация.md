
**Пагинация в SQL** — это разбивка большого результата запроса на небольшие порции (страницы), чтобы не передавать клиенту все данные за один раз. Это стандартный паттерн для интерфейсов, где нужно показывать списки: товары в каталоге, посты в блоге, сотрудников в HR-системе.
## LIMIT и OFFSET
Это самый распространённый и стандартный для многих СУБД способ.

[[LIMIT и OFFSET для пагинации]] - Например, в интернет-магазине на одной странице показывается 20 товаров.
[[Пагинация в интернет-магазине]] - `OFFSET 4` пропустил первые четыре строки. `LIMIT 4` взял строки с пятой по восьмую.
[[Для пагинации нужен стабильный порядок]] - Пагинация без нормального `ORDER BY` — источник странных багов.
[[Keyset-пагинация - альтернатива большому OFFSET]] - Для больших таблиц часто используют keyset-пагинацию. Её ещё называют seek pagination.
