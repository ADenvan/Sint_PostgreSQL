
# Что такое LIMIT в SQL?

LIMIT обрезает результат до N строк. Незаменим для пагинации, топ-N запросов, превью таблиц. Разбираем синтаксис, OFFSET, отличия PostgreSQL и MySQL, частые ошибки и три задачи на тренировку.

---
## Зачем нужен LIMIT

У `LIMIT` есть три главных сценария.

Первый — **топ-N**.

Например:

- топ-10 самых популярных товаров;
- топ-5 авторов по просмотрам;
- топ-3 клиента по сумме заказов;
- 20 последних комментариев.

Второй — **пагинация**.

Это когда данные показываются страницами: по 10, 20, 50 строк. Например, каталог товаров, список пользователей, история заказов.

Третий — **быстрый просмотр данных**.

Когда ты только открыл незнакомую таблицу, часто не хочется сразу выгружать тысячи строк. Хочется спокойно посмотреть первые 5–10 записей и понять, что там вообще хранится.

```sql
SELECT *
FROM users
LIMIT 10;
```

Такой запрос удобен как первый взгляд на таблицу.

Но важно помнить: `LIMIT` не делает результат «первым» в человеческом смысле, если ты не указал сортировку. Он просто ограничивает количество строк.
