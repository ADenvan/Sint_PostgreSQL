
## OFFSET: пропустить первые строки

Рядом с `LIMIT` часто используют `OFFSET`.

`OFFSET` говорит: «пропусти столько-то строк, а потом начинай возвращать результат».

```sql
SELECT title, views
FROM videos
ORDER BY views DESC
LIMIT 3 OFFSET 3;
```

Читается так:

«Отсортируй видео по просмотрам по убыванию, пропусти первые 3 строки и верни следующие 3».

Если первая страница показывает места 1–3, то такой запрос покажет места 4–6.

Для нашей таблицы результат будет таким:

|title|views|
|---|--:|
|10 SELECT mistakes|150000|
|Linux history|90000|
|JOIN explained simply|80000|

`OFFSET 3` пропустил первые три строки рейтинга:

1. `Cats compile code`
2. `React hooks top`
3. `SQL in 30 minutes`

А `LIMIT 3` взял следующие три.
