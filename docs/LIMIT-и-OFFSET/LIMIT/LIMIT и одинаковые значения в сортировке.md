
## LIMIT и одинаковые значения в сортировке

Представь, что мы ищем топ-3 товаров по продажам.

```sql
SELECT product_id, sales_count
FROM product_stats
ORDER BY sales_count DESC
LIMIT 3;
```

А в таблице такие данные:

|product_id|sales_count|
|--:|--:|
|1|100|
|2|90|
|3|80|
|4|80|
|5|80|

Формально топ-3 вернёт только три строки. Но товаров с одинаковым результатом `80` несколько.

Какой из них попадёт третьим? Если сортировка только по `sales_count`, порядок между товарами с одинаковым значением может быть нестабильным.

Поэтому для предсказуемости добавляют второй критерий:

```sql
SELECT product_id, sales_count
FROM product_stats
ORDER BY sales_count DESC, product_id ASC
LIMIT 3;
```

Теперь при равном `sales_count` база отсортирует строки по `product_id`.

Это особенно важно для тестов, отчётов и задач в SQL-тренажёрах, где ожидается стабильный результат
