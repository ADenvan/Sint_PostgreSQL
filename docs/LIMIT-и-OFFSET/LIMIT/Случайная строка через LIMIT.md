
## Случайная строка через LIMIT

Иногда хочется получить случайную строку: случайный товар дня, случайный вопрос, случайную задачу.

В PostgreSQL:

```sql
SELECT id, name
FROM products
ORDER BY RANDOM()
LIMIT 1;
```

В MySQL:

```sql
SELECT id, name
FROM products
ORDER BY RAND()
LIMIT 1;
```

Работает красиво: база перемешивает строки случайным образом и берёт первую.

Но есть важный нюанс. На больших таблицах это может быть медленно.

Почему? Потому что базе нужно для каждой строки сгенерировать случайное значение, отсортировать строки по этому значению и только потом взять одну.

Для маленьких таблиц это нормально. Для таблиц на миллионы строк лучше искать другие способы случайной выборки.
