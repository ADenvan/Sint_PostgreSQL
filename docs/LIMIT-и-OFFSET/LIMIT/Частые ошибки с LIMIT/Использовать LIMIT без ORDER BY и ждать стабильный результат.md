
### Использовать LIMIT без ORDER BY и ждать стабильный результат

Плохой вариант:

```sql
SELECT id, email
FROM users
LIMIT 10;
```

Сегодня он может вернуть одни 10 строк, завтра другие. Особенно если таблица меняется, добавляются индексы или база выбирает другой план выполнения.

Если порядок важен, пиши явно:

```sql
SELECT id, email
FROM users
ORDER BY id ASC
LIMIT 10;
```
