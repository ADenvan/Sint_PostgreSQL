
### Делать пагинацию без стабильной сортировки

Плохо:

```sql
SELECT id, name
FROM products
ORDER BY popularity DESC
LIMIT 20 OFFSET 20;
```

Если у товаров одинаковая популярность, порядок между ними может быть нестабильным.

Лучше:

```sql
SELECT id, name
FROM products
ORDER BY popularity DESC, id ASC
LIMIT 20 OFFSET 20;
```

Уникальный ключ в конце сортировки помогает сделать страницы предсказуемыми.
