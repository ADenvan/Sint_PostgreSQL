
## LIMIT почти всегда используют с ORDER BY

`LIMIT` отвечает на вопрос: «сколько строк вернуть?»

`ORDER BY` отвечает на вопрос: «в каком порядке их расположить?»

Если тебе нужны 5 самых популярных видео, одного `LIMIT` недостаточно.

Плохо:

```sql
SELECT title, views
FROM videos
LIMIT 5;
```

Такой запрос означает: «дай какие-нибудь 5 строк». Он не означает «дай топ-5».

Правильно:

```sql
SELECT title, views
FROM videos
ORDER BY views DESC
LIMIT 5;
```

Вот теперь смысл точный: сначала отсортировать видео по просмотрам от большего к меньшему, потом взять первые 5 строк.

Запомни простое правило:

**если важен порядок строк, всегда пиши `ORDER BY`.**

`LIMIT` без `ORDER BY` можно использовать для быстрого просмотра таблицы при разработке, но не для отчётов, страниц сайта и бизнес-логики.
