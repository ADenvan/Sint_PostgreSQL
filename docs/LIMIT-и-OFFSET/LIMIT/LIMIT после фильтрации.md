
## LIMIT после фильтрации

Важно понимать порядок смысла запроса.

Например:

```sql
SELECT id, name, price
FROM products
WHERE category = 'Books'
ORDER BY price ASC
LIMIT 5;
```

Читается так:

1. Взять товары.
2. Оставить только категорию `Books`.
3. Отсортировать книги по цене от дешёвых к дорогим.
4. Вернуть первые 5.

`LIMIT` применяется не к исходной таблице целиком, а к результату запроса после фильтрации и сортировки.

То есть это не «возьми первые 5 товаров, а потом выбери книги». Это «выбери книги, отсортируй их и возьми первые 5».
