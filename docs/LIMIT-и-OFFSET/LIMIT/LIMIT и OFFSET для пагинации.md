
## LIMIT и OFFSET для пагинации

[[Пагинация]] — это показ данных страницами.

Например, в интернет-магазине на одной странице показывается 20 товаров.

Тогда:

- страница 1: пропустить 0, взять 20;
- страница 2: пропустить 20, взять 20;
- страница 3: пропустить 40, взять 20;
- страница 4: пропустить 60, взять 20.

Формула такая:

```sql
LIMIT page_size OFFSET (page_number - 1) * page_size
```

Для страницы 1 при размере страницы 20:

```sql
LIMIT 20 OFFSET 0
```

Для страницы 2:

```sql
LIMIT 20 OFFSET 20
```

Для страницы 3:

```sql
LIMIT 20 OFFSET 40
```

Пример запроса:

```sql
SELECT id, name, price
FROM products
ORDER BY id ASC
LIMIT 20 OFFSET 40;
```

Это третья страница товаров, если на странице 20 товаров.
