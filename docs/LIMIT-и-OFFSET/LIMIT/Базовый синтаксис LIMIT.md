
## Базовый синтаксис LIMIT

Самая простая форма:

```sql
SELECT column_1, column_2
FROM table_name
LIMIT 5;
```

Это значит: верни не больше 5 строк.

Например, есть таблица `videos`.

```sql
SELECT title, views
FROM videos
LIMIT 5;
```

Запрос вернёт максимум 5 строк из таблицы `videos`.

Но какие именно 5 строк? Без `ORDER BY` на это лучше не рассчитывать.

База данных не обязана возвращать строки в порядке добавления, по `id`, по дате или «как красиво выглядит». Если порядок важен, его нужно указать явно.
