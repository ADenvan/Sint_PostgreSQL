
## Пример: [[пагинация]] в интернет-магазине

Допустим, есть таблица `products`.

|id|name|category|price|popularity|
|--:|---|---|--:|--:|
|1|iPhone 15|Electronics|90000|980|
|2|Bosch kettle|Home|4500|320|
|3|Clean Code|Books|2000|850|
|4|DeLonghi coffee machine|Home|35000|410|
|5|MacBook Air|Electronics|130000|920|
|6|SQL in one month|Books|1500|670|
|7|Pixel 8|Electronics|75000|740|
|8|LG fridge|Home|65000|280|
|9|Multicooker|Home|8000|560|
|10|JavaScript guide|Books|1800|510|

Нужно показать вторую страницу каталога: по 4 товара на странице, сортировка по популярности.

Первая страница — первые 4 товара.

Вторая страница — пропускаем 4 товара и берём следующие 4.

```sql
SELECT id, name, popularity
FROM products
ORDER BY popularity DESC
LIMIT 4 OFFSET 4;
```

Результат:

|id|name|popularity|
|--:|---|--:|
|6|SQL in one month|670|
|9|Multicooker|560|
|10|JavaScript guide|510|
|4|DeLonghi coffee machine|410|

Почему именно они?

Полный порядок по популярности такой:

|position|name|popularity|
|--:|---|--:|
|1|iPhone 15|980|
|2|MacBook Air|920|
|3|Clean Code|850|
|4|Pixel 8|740|
|5|SQL in one month|670|
|6|Multicooker|560|
|7|JavaScript guide|510|
|8|DeLonghi coffee machine|410|
|9|Bosch kettle|320|
|10|LG fridge|280|

`OFFSET 4` пропустил первые четыре строки. `LIMIT 4` взял строки с пятой по восьмую.
