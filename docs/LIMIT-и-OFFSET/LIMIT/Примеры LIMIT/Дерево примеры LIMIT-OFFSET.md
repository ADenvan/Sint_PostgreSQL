## Главное про LIMIT

`LIMIT` ограничивает количество строк в результате.

Базовая форма:

```sql
SELECT column_1, column_2
FROM table_name
LIMIT 10;
```

Но почти всегда вместе с `LIMIT` нужен `ORDER BY`.

```sql
SELECT column_1, column_2
FROM table_name
ORDER BY column_1
LIMIT 10;
```

Без `ORDER BY` база не обязана возвращать строки в понятном и стабильном порядке.

`OFFSET` позволяет пропустить первые строки.

```sql
SELECT id, name
FROM products
ORDER BY id
LIMIT 20 OFFSET 40;
```

Так обычно делают простую пагинацию: страница 3, если на странице 20 строк.

`LIMIT` полезен для топов, страниц каталога, лент, админок, быстрых проверок и аналитических рейтингов.

На больших значениях `OFFSET` запросы могут тормозить, потому что базе приходится пропускать много строк. Для больших лент и глубоких страниц часто используют keyset-пагинацию: не «пропусти миллион строк», а «покажи следующие строки после последнего увиденного значения».

Главная мысль простая: `LIMIT` — это аккуратный способ не тащить из базы весь мир. Но чтобы результат был правильным, ему почти всегда нужен надёжный порядок через `ORDER BY`.
