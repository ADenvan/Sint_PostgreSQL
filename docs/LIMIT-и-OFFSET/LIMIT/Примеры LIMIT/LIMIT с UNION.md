
## LIMIT с UNION

`LIMIT` можно использовать вместе с `UNION`, но важно понимать, к чему он применяется.

Например:

```sql
SELECT name
FROM authors

UNION

SELECT name
FROM editors

ORDER BY name
LIMIT 10;
```

Здесь `LIMIT 10` применяется ко всему итоговому результату после объединения.

То есть SQL сначала объединит имена авторов и редакторов, затем отсортирует общий список, а потом возьмёт 10 строк.

Если нужно ограничить каждую часть отдельно, используют скобки или подзапросы.

```sql
(SELECT name
 FROM authors
 ORDER BY name
 LIMIT 10)

UNION ALL

(SELECT name
 FROM editors
 ORDER BY name
 LIMIT 10);
```

В таком случае каждая часть сначала берёт свои 10 строк, а потом результаты объединяются.

Это разные задачи:

- `LIMIT` в самом конце — ограничить общий результат;
- `LIMIT` внутри частей — ограничить каждый отдельный запрос.
