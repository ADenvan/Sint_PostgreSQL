
## Пример: топ-3 видео по просмотрам

Допустим, есть таблица `videos`.

|id|title|author|views|likes|
|--:|---|---|--:|--:|
|1|SQL in 30 minutes|Code Academy|250000|12000|
|2|Cats compile code|Funny Devs|1200000|95000|
|3|JOIN explained simply|DB Guru|80000|4500|
|4|Cooking borscht for devs|Tech Cooks|30000|1800|
|5|10 SELECT mistakes|DB Guru|150000|8900|
|6|React hooks top|Web Dev|500000|25000|
|7|Linux history|OS Lessons|90000|5500|

Нужно получить три самых просматриваемых видео.

```sql
SELECT title, views
FROM videos
ORDER BY views DESC
LIMIT 3;
```

Результат:

|title|views|
|---|--:|
|Cats compile code|1200000|
|React hooks top|500000|
|SQL in 30 minutes|250000|

Что произошло:

1. SQL взял строки из `videos`.
2. Отсортировал их по `views` по убыванию.
3. Оставил только первые 3 строки.

Именно так обычно делают топы: сортировка плюс ограничение.
