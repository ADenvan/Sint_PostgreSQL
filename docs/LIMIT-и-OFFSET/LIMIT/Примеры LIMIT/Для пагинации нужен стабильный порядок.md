
## Для пагинации нужен стабильный порядок

Пагинация без нормального `ORDER BY` — источник странных багов.

Пользователь открывает первую страницу, видит одни товары. Потом открывает вторую — и внезапно там повторяется товар с первой страницы. Или какой-то товар пропадает между страницами.

Так бывает, когда порядок нестабильный.

Плохо:

```sql
SELECT id, name, price
FROM products
LIMIT 20 OFFSET 20;
```

Здесь нет сортировки. База может вернуть строки в одном порядке сегодня и в другом завтра.

Лучше:

```sql
SELECT id, name, price
FROM products
ORDER BY id ASC
LIMIT 20 OFFSET 20;
```

Ещё лучше, если сортируешь по колонке, где могут быть одинаковые значения, добавлять уникальный ключ.

Например, у нескольких товаров может быть одинаковая популярность.

```sql
SELECT id, name, popularity
FROM products
ORDER BY popularity DESC, id ASC
LIMIT 20 OFFSET 20;
```

Так порядок становится стабильным: сначала сортируем по популярности, а если популярность одинаковая — по `id`.

Для страниц сайта это особенно важно. Пользователь не должен видеть «прыгающие» строки.
