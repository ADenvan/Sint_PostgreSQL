# Частые ошибки новичков
- [[Добавить в SELECT колонку, которой нет в GROUP BY]] - роблема: в одной стране может быть много имён. База не знает, какое имя показать.
- [[Фильтровать агрегаты через WHERE]] - Так нельзя, потому что `WHERE` работает до группировки.
- [[Группировать по слишком точному значению]] - Если в `created_at` есть часы, минуты и секунды, групп получится слишком много.
- [[Забыть про NULL]] - Если группировать по колонке, где есть `NULL`, все `NULL` попадут в одну отдельную группу.
