
### Группировать по месяцу без года

Плохой вариант для данных за несколько лет:

```sql
SELECT
  EXTRACT(MONTH FROM created_at) AS month,
  SUM(amount) AS total_amount
FROM orders
GROUP BY 1
ORDER BY 1;
```

Так январь разных лет смешается.

Лучше:

```sql
SELECT
  EXTRACT(YEAR FROM created_at) AS year,
  EXTRACT(MONTH FROM created_at) AS month,
  SUM(amount) AS total_amount
FROM orders
GROUP BY 1, 2
ORDER BY 1, 2;
```

Или:

```sql
SELECT
  DATE_TRUNC('month', created_at) AS month,
  SUM(amount) AS total_amount
FROM orders
GROUP BY 1
ORDER BY 1;
```
