
### Группировать по слишком точному значению

Например:

```sql
SELECT
  created_at,
  COUNT(*) AS orders_count
FROM orders
GROUP BY created_at;
```

Если в `created_at` есть часы, минуты и секунды, групп получится слишком много.

Для отчёта по месяцам лучше так:

```sql
SELECT
  DATE_TRUNC('month', created_at) AS month,
  COUNT(*) AS orders_count
FROM orders
GROUP BY 1
ORDER BY 1;
```
