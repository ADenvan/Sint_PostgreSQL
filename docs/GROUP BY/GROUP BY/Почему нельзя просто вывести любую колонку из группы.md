
## Почему нельзя просто вывести любую колонку из группы

Представим группу по стране `RU`:

|id|name|country|
|--:|---|---|
|1|Anna|RU|
|3|Vera|RU|
|4|Gleb|RU|

Если запрос такой:

```sql
SELECT
  country,
  name,
  COUNT(*) AS users_count
FROM users
GROUP BY country;
```

то результат должен быть одной строкой на страну:

|country|name|users_count|
|---|---|--:|
|RU|?|3|

С `country` всё понятно: вся группа имеет значение `RU`.

С `COUNT(*)` тоже всё понятно: в группе 3 строки.

А вот с `name` непонятно. В группе три разных имени. Поэтому нормальная база данных не даст выполнить такой запрос.

Это не придирка SQL, а защита от странного отчёта.
