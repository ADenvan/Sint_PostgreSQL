
## Как читать запрос с GROUP BY

Возьмём запрос:

```sql
SELECT
  category,
  COUNT(*) AS products_count,
  AVG(price) AS avg_price
FROM products
WHERE is_active = true
GROUP BY category
HAVING COUNT(*) >= 5
ORDER BY avg_price DESC;
```

Читать его удобно не сверху вниз, а по смыслу:

1. Берём таблицу `products`.
2. Оставляем только активные товары.
3. Группируем товары по категории.
4. Для каждой категории считаем количество и среднюю цену.
5. Оставляем только категории, где товаров минимум 5.
6. Сортируем категории по средней цене от большей к меньшей.

Такой способ чтения помогает не путаться, особенно когда запрос становится длиннее.
