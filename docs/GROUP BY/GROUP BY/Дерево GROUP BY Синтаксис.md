
- [[Простая идея GROUP BY]] - Вот это и есть смысл `GROUP BY`: собрать одинаковые значения в группы и посчитать что-то внутри каждой группы.
- [[Базовый синтаксис GROUP BY]] - База берёт таблицу `users`, находит все строки, смотрит на значение в колонке `country` и собирает одинаковые страны вместе.
- [[GROUP BY по нескольким колонкам]] - Группировать можно не только по одной колонке. 
	- Можно посчитать пользователей по каждой паре `country` + `tier`: 
	- Здесь группа — это не просто страна. Группа — это комбинация значений.
> Чем больше колонок в `GROUP BY`, тем подробнее становится группировка.
- [[Главное правило SELECT при GROUP BY]] - Когда в запросе есть `GROUP BY`, в `SELECT` можно указывать только:
	1. колонки, которые есть в `GROUP BY`;
	2. агрегатные функции.
	- Потому что `country` есть в `GROUP BY`, а `COUNT(*)` — агрегатная функция.
- [[Почему нельзя просто вывести любую колонку из группы]] - А вот с `name` непонятно. В группе три разных имени. Поэтому нормальная база данных не даст выполнить такой запрос.
- [[GROUP BY и порядок выполнения запроса]] - Новичкам часто кажется, что SQL выполняется сверху вниз: сначала `SELECT`, потом `FROM`, потом `GROUP BY`. На самом деле логический порядок другой.
- [[WHERE и HAVING - в чём разница]] - 
	- `WHERE` и `HAVING` оба фильтруют данные, но делают это в разные моменты.
	- `WHERE` фильтрует строки до группировки.
	- `HAVING` фильтрует группы после группировки.
- [[GROUP BY и ORDER BY]] - После группировки результат можно отсортировать.
	- Здесь `ORDER BY users_count DESC` сортирует уже готовые группы: сначала страны с большим количеством пользователей, потом с меньшим.
- [[GROUP BY и DISTINCT]] - `GROUP BY` иногда путают с `DISTINCT`, потому что оба могут убрать повторяющиеся значения. `DISTINCT` нужен, когда ты хочешь получить список уникальных значений.
- [[COUNT(+) и COUNT(column)]] - Это важная тема, потому что новички часто думают, что `COUNT(*)` и `COUNT(email)` делают одно и то же.
	- если нужно посчитать строки — используй `COUNT(*)`;
	- если нужно посчитать заполненные значения в колонке — используй `COUNT(column)`.
- [[GROUP BY и NULL]] - `NULL` в `GROUP BY` ведёт себя особым образом: все строки с `NULL` в группируемой колонке попадают в одну группу. То есть `NULL` не исчезает сам по себе. Он образует отдельную группу.
- [[GROUP BY и SUM и AVG]] - 
	- `SUM` Один из самых частых сценариев — сумма по группам. 
	- `AVG` считает среднее значение внутри группы.
- [[GROUP BY по датам]] - С датами нужно быть аккуратным.
	- Для отчётов чаще группируют не по полной дате, а по периоду:  день, месяц, год.
- [[GROUP BY по месяцу - частая ловушка]] - Для отчётов по времени `DATE_TRUNC` часто удобнее и безопаснее.
