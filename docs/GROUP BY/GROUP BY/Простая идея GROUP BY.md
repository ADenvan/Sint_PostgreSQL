
## Простая идея GROUP BY

Представь таблицу заказов. В ней каждая строка — отдельный заказ:

|order_id|customer_id|amount|
|--:|--:|--:|
|1|101|500|
|2|102|300|
|3|101|700|
|4|103|200|
|5|101|100|

Если сделать обычный `SELECT`, ты увидишь все заказы по отдельности.

Но если написать:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count
FROM orders
GROUP BY customer_id;
```

то база сгруппирует строки по `customer_id`.

Результат:

|customer_id|orders_count|
|--:|--:|
|101|3|
|102|1|
|103|1|

Пять строк превратились в три строки: по одной строке на каждого клиента.

Вот это и есть смысл `GROUP BY`: собрать одинаковые значения в группы и посчитать что-то внутри каждой группы.
