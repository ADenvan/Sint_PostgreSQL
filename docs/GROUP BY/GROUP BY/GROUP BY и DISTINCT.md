
## GROUP BY и DISTINCT

`GROUP BY` иногда путают с `DISTINCT`, потому что оба могут убрать повторяющиеся значения.

Но задачи у них разные.

`DISTINCT` нужен, когда ты хочешь получить список уникальных значений.

```sql
SELECT DISTINCT country
FROM users;
```

Результат:

|country|
|---|
|RU|
|US|
|DE|

А `GROUP BY` нужен, когда ты хочешь не просто уникальные значения, а ещё и расчёты по каждой группе.

```sql
SELECT
  country,
  COUNT(*) AS users_count
FROM users
GROUP BY country;
```

Результат:

|country|users_count|
|---|--:|
|RU|100|
|US|50|
|DE|30|

Простая разница:

- `DISTINCT` отвечает: «Какие разные значения есть?»
- `GROUP BY` отвечает: «Какие группы есть и какие итоги у каждой группы?»

Если нужен только список стран — бери `DISTINCT`.

Если нужно количество пользователей по странам — бери `GROUP BY`.
