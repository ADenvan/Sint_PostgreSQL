
## CHECK

`CHECK` проверяет условие для строки.

Например, сумма заказа должна быть больше нуля:
```sql
amount NUMERIC(12, 2) NOT NULL CHECK (amount > 0)
```

Статус должен быть одним из разрешённых:

```sql
status TEXT NOT NULL CHECK (status IN ('pending', 'paid', 'shipped', 'cancelled'))
```

Возраст не должен быть отрицательным:
```sql
age INT CHECK (age >= 0)
```
`CHECK` помогает перенести простую здравую логику прямо в базу.

Без `CHECK` можно случайно получить заказ на отрицательную сумму или пользователя с возрастом `-5`.
С `CHECK` база просто не примет такую строку.
