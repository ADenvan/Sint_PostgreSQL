
## Деньги — только NUMERIC

Для денег лучше использовать точный тип:
```sql
price NUMERIC(12, 2) NOT NULL
```
`NUMERIC(12, 2)` означает: всего до 12 цифр, из них 2 после запятой.

Например:
```text
9999999999.99
```

Почему не `FLOAT`?

Потому что `FLOAT`, `REAL` и `DOUBLE PRECISION` хранят числа приблизительно. Это нормально для научных расчётов, графики или координат, но плохо для денег.

Классический пример проблемы:
```sql
SELECT 0.1::FLOAT + 0.2::FLOAT AS result;
```

Результат может оказаться не ровно `0.3`, а чем-то вроде:

```text
0.30000000000000004
```
Для цены товара, баланса пользователя или суммы заказа такое поведение не подходит.
Поэтому правило простое:
**Деньги, цены, комиссии, балансы — через `NUMERIC`, а не через `FLOAT`.**
