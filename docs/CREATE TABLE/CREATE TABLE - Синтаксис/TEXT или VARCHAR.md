
## TEXT или VARCHAR

В PostgreSQL `TEXT` и `VARCHAR(n)` очень похожи по производительности.

Например:
```sql
description TEXT
```
подходит для описаний, комментариев и длинных текстов.

А вот `VARCHAR(255)` нужен, когда у ограничения есть смысл:
```sql
email VARCHAR(255) NOT NULL
```

Если бизнес-правило говорит, что поле не должно быть длиннее определённого размера, можно использовать `VARCHAR(n)`.

Но не стоит ставить ограничения просто «на всякий случай». Если текст может быть любой разумной длины, в PostgreSQL часто спокойно используют `TEXT`.
