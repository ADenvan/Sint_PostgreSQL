
## NOT NULL

`NOT NULL` запрещает пустое значение.
```sql
email TEXT NOT NULL
```
Если попробовать вставить строку без email, база выдаст ошибку.

Это полезно для всего, без чего строка теряет смысл:
- email пользователя;
- сумма заказа;
- дата создания;
- название товара;
- статус платежа.

Если поле обязательно по смыслу, лучше написать `NOT NULL` сразу.
