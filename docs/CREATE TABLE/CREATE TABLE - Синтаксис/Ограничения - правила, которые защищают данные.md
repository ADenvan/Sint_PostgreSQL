
## Ограничения: правила, которые защищают данные

Ограничения, или constraints, — это правила, которые база проверяет при `INSERT` и `UPDATE`.
Если правило нарушено, база не запишет строку.

Посмотрим на пример таблицы заказов:
```sql
CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  number TEXT NOT NULL UNIQUE,
  customer_id INT NOT NULL REFERENCES customers(id),
  amount NUMERIC(12, 2) NOT NULL CHECK (amount > 0),
  status TEXT NOT NULL DEFAULT 'pending' CHECK (status IN ('pending', 'paid', 'shipped', 'cancelled'))
);
```
Здесь сразу несколько правил.
