
## UNIQUE

`UNIQUE` запрещает повторяющиеся значения.
```sql
email TEXT UNIQUE NOT NULL
```
Так база не даст создать двух пользователей с одной и той же почтой.

Ещё примеры:
```sql
number TEXT UNIQUE NOT NULL
```

для номера заказа;

```sql
slug TEXT UNIQUE NOT NULL
```

для адреса страницы;

```sql
phone TEXT UNIQUE
```
для телефона, если по правилам бизнеса он должен быть уникальным.

`UNIQUE` — это не просто украшение. Это защита от дублей, которые потом очень неприятно чистить.
