
### Не понимать, почему исчезли строки

Если строка есть в одной таблице, но нет подходящей строки во второй, `INNER JOIN` её уберёт.

Это не ошибка базы. Это смысл `INNER JOIN`.

Например:

- пользователь без заказов исчезнет;
- заказ без пользователя исчезнет;
- книга без автора исчезнет;
- товар без категории исчезнет.

Если такие строки нужно сохранить, используй внешний join, чаще всего `LEFT JOIN`.
