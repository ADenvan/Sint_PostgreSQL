
### Ошибка 3. Удивляться дубликатам

Если у пользователя 5 заказов, после `JOIN` он появится 5 раз.

Это нормально.

Если нужны уникальные пользователи:

```sql
SELECT DISTINCT
  u.id,
  u.name
FROM users u
JOIN orders o
  ON u.id = o.user_id;
```

Если нужно количество заказов:

```sql
SELECT
  u.id,
  u.name,
  COUNT(*) AS orders_count
FROM users u
JOIN orders o
  ON u.id = o.user_id
GROUP BY u.id, u.name;
```
