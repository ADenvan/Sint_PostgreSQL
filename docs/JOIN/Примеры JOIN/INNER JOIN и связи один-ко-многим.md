
## INNER JOIN и связи один-ко-многим

Очень часто `INNER JOIN` используют для связи один-ко-многим.

Например:

- один пользователь может иметь много заказов;
- один автор может иметь много книг;
- одна категория может иметь много товаров;
- один отдел может иметь много сотрудников.

В такой связи одна строка из первой таблицы может соединиться с несколькими строками из второй таблицы.

Пример:

```sql
SELECT
  c.name AS category,
  p.name AS product
FROM categories c
JOIN products p
  ON c.id = p.category_id;
```

Если в категории `Books` лежит 10 товаров, то категория `Books` появится в результате 10 раз — по одному разу рядом с каждым товаром.

Это нормальное поведение.
