
## INNER JOIN — это только совпадения

Очень важно: `INNER JOIN` не показывает «одинокие» строки.

Если пользователь есть, но заказов нет, он не попадёт в результат.

Если заказ есть, но пользователя для него нет, этот заказ тоже не попадёт в результат.

Можно представить так:

|Ситуация|Попадёт в результат `INNER JOIN`?|
|---|---|
|Пользователь есть и заказ есть|Да|
|Пользователь есть, заказа нет|Нет|
|Заказ есть, пользователя нет|Нет|

Поэтому `INNER JOIN` удобно использовать, когда тебе нужны только связанные данные.

Например:

- только пользователи, у которых есть заказы;
- только товары, у которых есть категория;
- только платежи, у которых есть заказ;
- только книги, у которых есть автор в базе.

Если нужно показать пользователей даже без заказов, нужен уже не `INNER JOIN`, а `LEFT JOIN`.
