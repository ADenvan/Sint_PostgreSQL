
## Базовый синтаксис

Общий вид такой:

```sql
SELECT
  columns
FROM table_a
INNER JOIN table_b
  ON table_a.key = table_b.key;
```

Слово `INNER` можно опустить:

```sql
SELECT
  columns
FROM table_a
JOIN table_b
  ON table_a.key = table_b.key;
```

Оба варианта означают одно и то же.

В реальном коде чаще пишут просто `JOIN`, потому что короче.
