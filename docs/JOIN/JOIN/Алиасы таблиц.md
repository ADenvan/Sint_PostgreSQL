
## Алиасы таблиц

В реальных запросах редко пишут полные имена таблиц каждый раз.

Вот так работает, но выглядит длинно:

```sql
SELECT
  users.name,
  orders.amount,
  orders.created_at
FROM users
JOIN orders
  ON users.id = orders.user_id;
```

Обычно используют алиасы — короткие имена таблиц:

```sql
SELECT
  u.name,
  o.amount,
  o.created_at
FROM users u
JOIN orders o
  ON u.id = o.user_id;
```

Здесь:

- `users u` означает: таблицу `users` дальше называем `u`;
- `orders o` означает: таблицу `orders` дальше называем `o`.

Логика запроса не меняется. Просто он становится короче и удобнее для чтения.

Особенно алиасы полезны, когда в запросе три, четыре или пять таблиц.
