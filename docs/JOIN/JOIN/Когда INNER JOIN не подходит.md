
## Когда INNER JOIN не подходит

`INNER JOIN` не подходит, если нужно сохранить строки без пары.

Например:

> Покажи всех пользователей, даже если они ничего не заказали.

Для такой задачи нужен `LEFT JOIN`.

Если использовать `INNER JOIN`, пользователи без заказов исчезнут из результата.

Сравни идею:

```sql
SELECT
  u.name,
  o.amount
FROM users u
JOIN orders o
  ON u.id = o.user_id;
```

Этот запрос покажет только пользователей с заказами.

А вот такой запрос уже покажет всех пользователей:

```sql
SELECT
  u.name,
  o.amount
FROM users u
LEFT JOIN orders o
  ON u.id = o.user_id;
```

У пользователей без заказов в колонках заказа будет `NULL`.
