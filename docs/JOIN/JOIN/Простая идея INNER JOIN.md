
## Простая идея INNER JOIN

`INNER JOIN` ищет совпадения между двумя таблицами.

Например:

- в `users.id` лежит идентификатор пользователя;
- в `orders.user_id` лежит идентификатор пользователя, который сделал заказ.

Если `users.id = orders.user_id`, значит эти строки связаны.

SQL берёт строку пользователя, находит подходящие строки заказов и склеивает их в одну результирующую строку.

Если совпадения нет, строка не попадает в результат.

Это главное свойство `INNER JOIN`:

> В результат попадают только те строки, у которых есть совпадение в обеих таблицах.
