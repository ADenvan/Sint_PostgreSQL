
## Зачем указывать имя таблицы перед колонкой

После `JOIN` в результате участвуют колонки сразу из нескольких таблиц.

Часто в разных таблицах есть одинаковые названия колонок.

Например, и в `users`, и в `orders` есть колонка `id`.

Если написать так:

```sql
SELECT
  id,
  name,
  amount
FROM users
JOIN orders
  ON users.id = orders.user_id;
```

база может не понять, какой именно `id` нужен: `users.id` или `orders.id`.

Поэтому лучше писать явно:

```sql
SELECT
  u.id AS user_id,
  o.id AS order_id,
  u.name,
  o.amount
FROM users u
JOIN orders o
  ON u.id = o.user_id;
```

Так запрос читается без догадок:

- `u.id` — идентификатор пользователя;
- `o.id` — идентификатор заказа.
