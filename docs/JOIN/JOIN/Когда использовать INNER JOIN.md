
## Когда использовать INNER JOIN

Используй `INNER JOIN`, когда тебе нужны только строки, у которых есть пара в другой таблице.

Например:

- заказы с существующими пользователями;
- товары с существующими категориями;
- книги с существующими авторами;
- платежи с существующими заказами;
- студенты, записанные хотя бы на один курс.

Хороший пример:

```sql
SELECT
  u.name,
  o.amount
FROM users u
JOIN orders o
  ON u.id = o.user_id;
```

Этот запрос не пытается показать всех пользователей. Он показывает только пользователей с заказами.
