
- [[Несколько ключевых функций и операторов для работы с датами]] - 
	1. **`CURRENT_DATE`** — возвращает текущую дату (без времени)
	2. **`INTERVAL`** — позволяет вычитать или прибавлять периоды времени
	3. **`::date`** — оператор приведения типа, превращает timestamp в дату
-  **Не используй `::date` на колонке в WHERE, если можно этого избежать:** Когда ты пишешь `purchased_at::date`, ты заставляешь базу применять функцию к каждой строке перед проверкой, что может замедлить запрос на больших данных. Лучше сравнивать исходный `timestamp` с `timestamp`
