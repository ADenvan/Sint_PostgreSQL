
## Сначала SELECT, потом DELETE

Перед удалением полезно сначала выполнить `SELECT` с тем же самым условием.
Например, вы хотите удалить пользователя с `id = 42`.

Сначала проверяем:
```sql
SELECT id, name, email
FROM users
WHERE id = 42;
```

Смотрим результат. Если это действительно нужный пользователь, только потом выполняем:
```sql
DELETE FROM users
WHERE id = 42;
```
Это простая привычка, которая спасает от дорогих ошибок.

Особенно важно делать так на реальных данных, а не в учебной песочнице.

## Проверка количества строк перед удалением

Если вы удаляете не одну строку, а много, полезно заранее узнать масштаб.

Например, хотим удалить старые сессии:
```sql
SELECT COUNT(*) AS rows_to_delete
FROM sessions
WHERE expires_at < NOW();
```

Если результат `47`, всё выглядит спокойно.

Если результат `470000`, стоит остановиться и подумать:
- точно ли условие правильное;
- не слишком ли большой объём для одного удаления;
- не повлияет ли это на пользователей;
- не лучше ли удалять данные пачками.

После проверки можно выполнять:
```sql
DELETE FROM sessions
WHERE expires_at < NOW();
```

`SELECT COUNT(*)` перед `DELETE` — очень хорошая привычка для всех операций, которые могут затронуть много строк.
