
## DELETE и права доступа

В реальной базе не каждый пользователь должен иметь право удалять данные.
Для `DELETE` нужны соответствующие права.

Это важно для безопасности. Например, аналитик может иметь право читать данные через `SELECT`, но не иметь права удалять пользователей, заказы или платежи.

На уровне идеи это выглядит так:
```sql
GRANT SELECT ON users TO analyst;
```
А право на удаление можно не выдавать.

Команда `DELETE` меняет данные необратимо для обычного пользователя, поэтому доступ к ней должен быть ограничен.
