
## Безопасный порядок действий перед DELETE

Для новичка хорошая схема такая:
1. Сформулировать условие удаления.
2. Выполнить `SELECT` с этим условием.
3. Проверить строки глазами или через `COUNT(*)`.
4. Если данные важные — открыть транзакцию.
5. Выполнить `DELETE`.
6. Проверить количество удалённых строк.
7. Сделать `COMMIT` или `ROLLBACK`.

Например:
```sql
BEGIN;

SELECT COUNT(*) AS rows_to_delete
FROM sessions
WHERE expires_at < NOW();

DELETE FROM sessions
WHERE expires_at < NOW();

COMMIT;
```

А если результат неожиданно большой:

```sql
ROLLBACK;
```
Эта схема чуть длиннее, чем просто написать один `DELETE`, зато намного спокойнее.
