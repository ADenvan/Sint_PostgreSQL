
## WHERE — самая важная часть DELETE

Самая страшная ошибка с `DELETE` — забыть `WHERE`.

Вот такой запрос удалит не одного пользователя, а **все строки** из таблицы:
```sql
DELETE FROM users;
```
После него таблица `users` станет пустой.

База данных не спросит: «Вы точно хотите удалить всех пользователей?»  
Она просто выполнит команду.

Поэтому правило номер один:
**Перед `DELETE` всегда думайте о `WHERE`.**

Хорошая привычка — начинать запрос так:
```sql
DELETE FROM users
WHERE
```
А уже потом дописывать условие.
Так мозг сразу привыкает: `DELETE` без условия — незаконченная и опасная команда.
