
## DELETE с RETURNING в PostgreSQL

В PostgreSQL у `DELETE` есть удобная возможность — `RETURNING`.
Она позволяет удалить строки и сразу увидеть, что именно было удалено.

Например:
```sql
DELETE FROM users
WHERE id = 2
RETURNING id, name, email;
```
Результат может быть таким:

|id|name|email|
|--:|---|---|
|2|Bob|[bob@example.com](mailto:bob@example.com)|

Это удобно, когда нужно:
- проверить удалённые строки;
- записать удалённые данные в лог;
- вернуть удалённый объект из API;
- убедиться, что удалился именно тот пользователь.

Можно даже вернуть все колонки:
```sql
DELETE FROM users
WHERE id = 2
RETURNING *;
```

Но на больших удалениях с `RETURNING *` нужно быть осторожным: если удалится много строк, база вернёт большой результат.
