
## DELETE удаляет строки, но не таблицу

`DELETE` убирает данные, но сама таблица остаётся.

Например:
```sql
DELETE FROM users
WHERE id = 2;
```
После этого таблица `users` всё ещё существует. У неё остаются те же колонки, индексы, ограничения, права доступа.

Если удалить все строки:
```sql
DELETE FROM users;
```
таблица тоже останется. Она просто будет пустой.

Это важно не путать с `DROP TABLE`.

`DROP TABLE` удаляет саму таблицу целиком:
```sql
DROP TABLE users;
```

После `DROP TABLE` исчезают и данные, и структура таблицы. Это уже не уборка строк, а снос самого шкафа вместе со всеми полками.
