
## `SUM` — посчитать сумму

`SUM` складывает значения в колонке.

Например, есть таблица заказов:

|id|customer_id|amount|
|--:|--:|--:|
|1|10|1200|
|2|10|800|
|3|15|2400|
|4|21|500|

Запрос:

```sql
SELECT SUM(amount) AS total_amount
FROM orders;
```

Результат:

|total_amount|
|--:|
|4900|

`SUM` используют для денег, количества товаров, баллов, просмотров, часов, километров — всего, что можно сложить.

Например, сумма оплаченных заказов:

```sql
SELECT SUM(amount) AS paid_amount
FROM orders
WHERE status = 'paid';
```

Здесь сначала сработает `WHERE`, останутся только оплаченные заказы, и уже по ним будет посчитана сумма.
