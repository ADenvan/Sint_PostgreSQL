
## `AVG` — посчитать среднее

`AVG` считает среднее значение.

Например, есть отзывы:

|id|product_id|rating|
|--:|--:|--:|
|1|100|5|
|2|100|4|
|3|100|5|
|4|100|3|

Запрос:

```sql
SELECT AVG(rating) AS avg_rating
FROM reviews
WHERE product_id = 100;
```

Результат:

|avg_rating|
|--:|
|4.25|

Среднее считается так:

Сумма значений делится на количество заполненных значений.

В примере:

```text
(5 + 4 + 5 + 3) / 4 = 4.25
```
