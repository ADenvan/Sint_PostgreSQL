
## `AVG` тоже пропускает `NULL`

Если часть значений равна `NULL`, они не участвуют в расчёте.

Например:

|id|rating|
|--:|--:|
|1|5|
|2|4|
|3|NULL|

Запрос:

```sql
SELECT AVG(rating) AS avg_rating
FROM reviews;
```

Посчитает не так:

```text
(5 + 4 + 0) / 3
```

А так:

```text
(5 + 4) / 2
```

Результат:

|avg_rating|
|--:|
|4.5|

Это логично: `NULL` означает не «ноль», а «значение неизвестно» или «значения нет».

Если оценка неизвестна, её нельзя честно использовать в среднем.
