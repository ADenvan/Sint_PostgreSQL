
- [[COUNT - посчитать строки]] - `COUNT` отвечает на вопрос «сколько?».
	- Он считает количество строк в таблице.
- [[COUNT(+), COUNT(column) и COUNT(DISTINCT column)]] - У `COUNT` есть несколько важных форм.
	- `COUNT(*)` не смотрит, заполнены ли отдельные колонки. Ему важно только количество строк.
	- `COUNT(column)` считает только заполненные значения. Такой запрос посчитает только строки, где `email` не равен `NULL`.
	- `COUNT(DISTINCT column)` считает уникальные значения. Если нужно посчитать не все значения, а только разные, используют `DISTINCT`.
- [[SUM - посчитать сумму]] - `SUM` складывает значения в колонке.
	- `SUM` используют для денег, количества товаров, баллов, просмотров, часов, километров — всего, что можно сложить.
	- [[Важная особенность SUM - NULL не превращается в ноль]] - `SUM` пропускает значения `NULL`.
- [[AVG - посчитать среднее]] - `AVG` считает среднее значение.
	- [[AVG тоже пропускает NULL]] - Если часть значений равна `NULL`, они не участвуют в расчёте.
	- [[Округление результата AVG]] - Среднее часто получается дробным. В PostgreSQL для целочисленной колонки `AVG` возвращает точное значение типа `NUMERIC`.
- [[MIN - найти самое маленькое значение]] - `MIN` возвращает минимальное значение в колонке.
- [[MAX - найти самое большое значение]] - `MAX` возвращает максимальное значение.
	- [[MIN и MAX по тексту - осторожно с порядком]] - По строкам `MIN` и `MAX` работают не как «самое короткое» или «самое длинное», а по порядку сортировки текста.
