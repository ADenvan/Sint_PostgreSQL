
## `MIN` и `MAX` по тексту: осторожно с порядком

По строкам `MIN` и `MAX` работают не как «самое короткое» или «самое длинное», а по порядку сортировки текста.

Например, есть значения:

|version|
|---|
|1|
|2|
|10|

Если они хранятся как текст, порядок может оказаться неожиданным:

```sql
SELECT
  MIN(version) AS min_version,
  MAX(version) AS max_version
FROM app_versions;
```

Для текстовых значений `'10'` может идти раньше `'2'`, потому что сравнение идёт посимвольно: сначала сравнивается первый символ.

Поэтому версии, номера и другие числовые значения лучше хранить в числовых колонках, если вы планируете сравнивать их как числа.
