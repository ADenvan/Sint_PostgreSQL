
## Как читать запрос с агрегатами и `GROUP BY`

Возьмём запрос:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count,
  SUM(amount) AS total_amount
FROM orders
GROUP BY customer_id;
```

Его удобно читать так:

1. Возьми таблицу `orders`.
2. Разбей заказы на группы по `customer_id`.
3. Для каждого клиента посчитай количество заказов через `COUNT(*)`.
4. Для каждого клиента посчитай сумму заказов через `SUM(amount)`.
5. Покажи одну строку на каждого клиента.

То есть результат будет не «одна строка на заказ», а «одна строка на клиента».
