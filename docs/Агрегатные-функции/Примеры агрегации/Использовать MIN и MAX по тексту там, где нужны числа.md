
## Использовать `MIN` и `MAX` по тексту там, где нужны числа

Если числа лежат в текстовой колонке, результат может удивить.

```sql
SELECT MAX(version) AS latest_version
FROM app_versions;
```

Для строк значения сравниваются как текст. Поэтому для числовых сравнений лучше хранить данные в числовом формате или заранее приводить типы, если это безопасно.
