
## Пример: отчёт по каждому клиенту

Теперь посчитаем статистику отдельно по каждому клиенту:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count,
  SUM(amount) AS total_amount,
  AVG(amount) AS avg_amount
FROM orders
WHERE status = 'paid'
GROUP BY customer_id
ORDER BY customer_id;
```

Результат:

|customer_id|orders_count|total_amount|avg_amount|
|--:|--:|--:|--:|
|10|2|2000|1000|
|21|2|500|500|

Обрати внимание на клиента 21.

У него два оплаченных заказа, поэтому `COUNT(*)` вернул 2.

Но сумма есть только в одном заказе, поэтому `SUM(amount)` вернул 500, а `AVG(amount)` тоже посчитал среднее только по заполненным значениям.
