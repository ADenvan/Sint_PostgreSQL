
## INSERT FROM SELECT: вставка результата запроса

`INSERT` умеет вставлять не только готовые значения из `VALUES`. Он может взять строки из результата другого `SELECT`.

Например, у нас есть таблица `orders` с заказами и таблица `orders_archive` для архива. Мы хотим перенести старые завершённые заказы в архивную таблицу.
^i1
```sql
INSERT INTO orders_archive (id, customer_id, amount, archived_at)
SELECT id, customer_id, amount, NOW()
FROM orders
WHERE status = 'completed'
  AND created_at < '2024-01-01';
```

^be9427

Здесь происходит важная вещь: `SELECT` сначала находит подходящие строки, а `INSERT` вставляет результат в другую таблицу.

Такой подход используют для:

- архивирования данных;
- миграций;
- заполнения новых таблиц;
- backfill-операций;
- переноса данных между похожими структурами;
- подготовки агрегированных или очищенных данных.

Например, можно не просто копировать значения, а сразу преобразовывать их:

```sql
INSERT INTO user_emails (user_id, email_lower)
SELECT id, LOWER(email)
FROM users
WHERE email IS NOT NULL;
```

Это читается почти как обычная инструкция: «возьми пользователей с email, приведи email к нижнему регистру и вставь результат в другую таблицу».
