
## Зачем нужен INSERT

Почти любые данные в приложении когда-то появились через вставку:

- пользователь зарегистрировался;
- клиент оформил заказ;
- студент отправил решение задачи;
- покупатель оставил отзыв;
- система записала событие в лог;
- администратор добавил новый тариф.

Всё это на уровне базы обычно превращается в команду вида:

```sql
INSERT INTO table_name (column_1, column_2)
VALUES (value_1, value_2);
```

То есть смысл очень простой: **вставить в такую-то таблицу новую строку с такими-то значениями**.
