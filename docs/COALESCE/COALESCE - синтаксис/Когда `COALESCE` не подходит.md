
## Когда `COALESCE` не подходит

`COALESCE` проверяет только `NULL`.
Он не считает плохими значениями:
- 0;
- `FALSE`;
- пустую строку;
- отрицательное число;
- дату из прошлого;
- неизвестный статус вроде `unknown`.

Например:

```sql
SELECT COALESCE(0, 100) AS result;
```

Результат:

| result |
| -----: |
|      0 |

Потому что 0 — это не `NULL`.

Ещё пример:

```sql
SELECT COALESCE(FALSE, TRUE) AS result;
```

Результат:

|result|
|---|
|false|

Потому что `FALSE` — это нормальное boolean-значение, а не отсутствие значения.
Если тебе нужно заменить не только `NULL`, но и 0, пустую строку или какой-то специальный статус, обычно нужен `CASE` или связка с `NULLIF`.

Например, заменить 0 на 100:

```sql
SELECT COALESCE(NULLIF(score, 0), 100) AS score_value
FROM results;
```

Здесь `NULLIF(score, 0)` сначала превращает 0 в `NULL`, а потом `COALESCE` заменяет его на 100.
