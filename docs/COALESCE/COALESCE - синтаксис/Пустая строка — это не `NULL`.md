
## Пустая строка — это не `NULL`

Очень частая ловушка: `COALESCE` работает только с `NULL`.
Пустая строка — это не `NULL`.

Например:

```sql
SELECT COALESCE('', 'default') AS result;
```

Результат будет пустой строкой, а не `default`.

Почему?

Потому что пустая строка — это значение. Просто оно состоит из нуля символов.
Для SQL это не то же самое, что отсутствие значения.

Если нужно считать и `NULL`, и пустую строку отсутствием значения, используют связку `NULLIF` и `COALESCE`.

```sql
SELECT COALESCE(NULLIF(value, ''), 'default') AS clean_value
FROM settings;
```

Разберём:

```sql
NULLIF(value, '')
```

возвращает `NULL`, если `value` равен пустой строке.

А потом `COALESCE` заменяет этот `NULL` на `default`.

Так мы обрабатываем сразу два случая:

- значение действительно `NULL`;
- значение есть, но оно пустая строка.
