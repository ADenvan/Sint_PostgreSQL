
## `COALESCE` и строки

`COALESCE` часто используют для текстовых полей.

Например, нужно собрать контактное имя клиента:

```sql
SELECT
  id,
  COALESCE(company_name, contact_name, email, 'Unknown') AS contact_label
FROM customers;
```

Логика:

1. Если есть название компании — показываем его.
2. Если компании нет — показываем имя контакта.
3. Если имени нет — показываем email.
4. Если нет вообще ничего — показываем `Unknown`.

Такой запрос удобен для списков, CRM, админок и таблиц, где нужно показать человеку хоть какую-то понятную подпись.
