
# COALESCE в SQL: как заменить NULL на понятное значение

COALESCE — это «верни первое не-NULL значение из списка». Простыми словами: дефолты для отсутствующих данных, fallback-цепочки (никнейм → имя → 'Гость'), безопасные арифметические операции и NULLIF в паре. С таблицами и частыми ошибками.

`COALESCE` — это функция SQL, которая возвращает **первое значение, которое не равно `NULL`**.

Проще говоря, это запасной план на случай пустоты:

«Возьми никнейм. Если никнейма нет — возьми имя. Если и имени нет — покажи значение по умолчанию».

Например:

```sql
SELECT COALESCE(nickname, full_name, 'Guest') AS display_name
FROM users;
```

Такой запрос говорит базе:
1. Если `nickname` заполнен — верни его.
2. Если `nickname` равен `NULL`, попробуй `full_name`.
3. Если и `full_name` равен `NULL`, верни `'Guest'`.

`COALESCE` очень часто используют в отчётах, интерфейсах, выгрузках и расчётах, чтобы вместо пустого `NULL` получить понятное значение.

# COALESCE Синтаксис
- [[Базовый синтаксис `COALESCE`]] - Аргументов может быть два, три, пять — сколько нужно.
- [[`COALESCE` не меняет данные в таблице]] - Важно понимать: `COALESCE` в `SELECT` не записывает новое значение в таблицу.
- [[`COALESCE` для безопасной арифметики]] - Один из самых частых сценариев — заменить `NULL` на 0 перед расчётом.
	- Если по смыслу отсутствующие баллы нужно считать нулём, используем `COALESCE`:
- [[Когда нельзя бездумно заменять `NULL` на 0]] - `COALESCE` — полезный инструмент, но применять его нужно по смыслу. 
- [[`COALESCE` с агрегатами]] - Агрегатные функции тоже часто возвращают `NULL`.
- [[`COALESCE` с `AVG`, `MIN` и `MAX`]] - Если подходящих строк нет, `AVG`, `MIN` и `MAX` тоже могут вернуть `NULL`.
- [[`COALESCE` и строки]] - `COALESCE` часто используют для текстовых полей.
- [[Пустая строка — это не `NULL`]] - Очень частая ловушка: `COALESCE` работает только с `NULL`. Пустая строка — это не `NULL`.
- [[`NULLIF` - обратная идея]] - Если `COALESCE` заменяет `NULL` нормальным значением, то `NULLIF` делает обратное: превращает выбранное значение в `NULL`.
- [[`NULLIF` для безопасного деления]] - Самый практичный пример `NULLIF` — защита от деления на ноль. Если `orders_count = 0`, база получит деление на ноль. Это ошибка.
- [[`COALESCE` вместо `CASE`]] - Но `COALESCE` короче и читается лучше, когда логика простая: «возьми первое не `NULL`». `CASE` нужен, когда условие сложнее.
- [[Типы данных в `COALESCE`]] - Все аргументы `COALESCE` должны быть совместимы по типам.
- [[`COALESCE` в `WHERE` - когда лучше не надо]] - Технически `COALESCE` можно использовать в `WHERE`.
	- в `WHERE` для проверки пустоты чаще писать `IS NULL` или `IS NOT NULL`.
- [[Когда `COALESCE` не подходит]] - `COALESCE` проверяет только `NULL`.
