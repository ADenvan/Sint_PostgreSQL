
## Простое правило для ON и WHERE

Правило не абсолютное на все случаи жизни, но для новичка очень полезное:

Если условие ограничивает строки правой таблицы при соединении — чаще клади его в `ON`.

Если условие фильтрует основную левую таблицу — чаще клади его в `WHERE`.

Например, хотим взять только активных учеников, но оценки справа оставить необязательными:

```sql
SELECT
  s.name,
  g.score
FROM students AS s
LEFT JOIN grades AS g
  ON s.id = g.student_id
WHERE s.is_active = true;
```

Здесь `s.is_active = true` относится к левой таблице. Мы действительно хотим убрать неактивных учеников из результата.

А если хотим показать всех активных учеников и только оценки за конкретный тест, условие по правой таблице лучше положить в `ON`.

```sql
SELECT
  s.name,
  g.score
FROM students AS s
LEFT JOIN grades AS g
  ON s.id = g.student_id
 AND g.test_id = 7
WHERE s.is_active = true;
```

Так запрос читается правильно:

- слева берём активных учеников;
- справа подставляем оценку за тест `7`, если она есть;
- если оценки нет — ученик всё равно остаётся.
