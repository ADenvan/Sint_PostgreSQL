
## Базовый синтаксис LEFT JOIN

Общая форма такая:

```sql
SELECT
  columns
FROM table_a AS a
LEFT JOIN table_b AS b
  ON a.id = b.table_a_id;
```

Здесь `table_a` — левая таблица. Она стоит после `FROM`.

`table_b` — правая таблица. Она стоит после `LEFT JOIN`.

Слово `LEFT` означает: **левая таблица сохраняется полностью**.

Можно читать запрос почти по-русски:

«Возьми строки из `table_a`. Попробуй подобрать к ним строки из `table_b` по условию в `ON`. Если справа ничего не нашлось — всё равно оставь строку из `table_a`, а справа поставь `NULL`».
