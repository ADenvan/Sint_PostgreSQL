
## Почему SUM нужно оборачивать в COALESCE

В запросе выше было:

```sql
COALESCE(SUM(o.amount), 0) AS total_spent
```

Почему не просто `SUM(o.amount)`?

Потому что если у пользователя нет заказов, справа нет сумм для сложения. Для такого пользователя `SUM(o.amount)` вернёт `NULL`.

Для отчёта обычно удобнее показать `0`, а не пустоту. Поэтому используют `COALESCE`.

```sql
COALESCE(SUM(o.amount), 0)
```

Это означает: «посчитай сумму, а если получился `NULL`, покажи `0`».

Важно: мы не меняем данные в таблице. Мы просто красиво оформляем результат запроса.
