
## Главное про LEFT JOIN

`LEFT JOIN` сохраняет все строки из левой таблицы.

Если справа есть совпадение, SQL подставляет данные из правой таблицы.

Если совпадения нет, строка слева всё равно остаётся, а в колонках правой таблицы появляется `NULL`.

Базовая форма:

```sql
SELECT
  a.columns,
  b.columns
FROM table_a AS a
LEFT JOIN table_b AS b
  ON a.id = b.table_a_id;
```

`LEFT JOIN` особенно полезен, когда нужно увидеть полную картину: всех пользователей, все товары, все уроки, все записи — включая те, у которых пока нет связанных данных.

Чтобы найти строки без пары, используют паттерн:

```sql
SELECT
  a.columns
FROM table_a AS a
LEFT JOIN table_b AS b
  ON a.id = b.table_a_id
WHERE b.id IS NULL;
```

Самая частая ловушка: фильтр по правой таблице в `WHERE` может превратить `LEFT JOIN` почти в `INNER JOIN`. Если нужно сохранить строки слева, условия по правой таблице часто надо переносить в `ON`.

После `LEFT JOIN` для подсчёта совпадений обычно используют `COUNT(b.id)`, а не `COUNT(*)`.

Главная идея простая: `LEFT JOIN` — это способ сказать базе данных: «Покажи мне всё слева. А если справа что-то нашлось — добавь. Если не нашлось — не прячь строку, мне важно это увидеть».
