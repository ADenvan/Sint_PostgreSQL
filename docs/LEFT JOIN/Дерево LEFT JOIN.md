
# Что такое LEFT JOIN в SQL?

LEFT JOIN — соединение таблиц, при котором ВСЕ строки левой таблицы попадают в результат. Если справа пары нет, ставится NULL. Разбираем синтаксис, отличие от INNER JOIN, поиск 'сирот' и три задачи.

`LEFT JOIN` — это соединение таблиц, при котором в результат попадают **все строки из левой таблицы**.

Если для строки из левой таблицы нашлась подходящая строка в правой таблице — SQL покажет данные из обеих таблиц. Если пары справа нет — строка всё равно останется в результате, а в колонках правой таблицы будет `NULL`.

Полное название — `LEFT OUTER JOIN`, но слово `OUTER` почти всегда опускают. Поэтому:

```sql
LEFT JOIN
```

и

```sql
LEFT OUTER JOIN
```

означают одно и то же.

Главная идея такая: `LEFT JOIN` не выбрасывает строки из основной таблицы. Он бережно сохраняет их и показывает: «вот эта строка есть, но справа для неё ничего не нашлось».
