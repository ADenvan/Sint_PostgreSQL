
## Пример: товары с хорошей средней оценкой

Есть таблица `reviews`:

|id|product_id|rating|
|--:|--:|--:|
|1|10|5|
|2|10|4|
|3|10|5|
|4|20|3|
|5|20|4|
|6|30|5|

Задача: показать товары со средней оценкой от 4.5.

```sql
SELECT
  product_id,
  COUNT(*) AS reviews_count,
  AVG(rating) AS avg_rating
FROM reviews
GROUP BY product_id
HAVING AVG(rating) >= 4.5
ORDER BY avg_rating DESC;
```

Результат:

|product_id|reviews_count|avg_rating|
|--:|--:|--:|
|30|1|5.0000|
|10|3|4.6667|

Но у товара `30` всего один отзыв. Иногда это плохо для аналитики: один восторженный отзыв ещё не значит, что товар действительно стабильно хороший.

Добавим второе условие: отзывов должно быть минимум 3.

```sql
SELECT
  product_id,
  COUNT(*) AS reviews_count,
  AVG(rating) AS avg_rating
FROM reviews
GROUP BY product_id
HAVING COUNT(*) >= 3
   AND AVG(rating) >= 4.5
ORDER BY avg_rating DESC;
```

Результат:

|product_id|reviews_count|avg_rating|
|--:|--:|--:|
|10|3|4.6667|

Теперь результат честнее: мы оставили только товары, у которых и оценка высокая, и отзывов достаточно.
