
## Пример: страны с большим количеством пользователей

Есть таблица `users`:

|id|name|country|status|
|--:|---|---|---|
|1|Anna|RU|active|
|2|Bob|US|active|
|3|Vera|RU|inactive|
|4|Gleb|RU|active|
|5|Dan|US|active|
|6|Eva|DE|active|

Задача: показать страны, где активных пользователей минимум 2.

```sql
SELECT
  country,
  COUNT(*) AS active_users_count
FROM users
WHERE status = 'active'
GROUP BY country
HAVING COUNT(*) >= 2
ORDER BY active_users_count DESC;
```

Результат:

|country|active_users_count|
|---|--:|
|RU|2|
|US|2|

Что произошло:

- `WHERE status = 'active'` убрал неактивных пользователей;
- `GROUP BY country` собрал оставшихся пользователей по странам;
- `HAVING COUNT(*) >= 2` оставил только страны, где активных пользователей минимум 2.

Германия не попала в результат, потому что там только один активный пользователь.
