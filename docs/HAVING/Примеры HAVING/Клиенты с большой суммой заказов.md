
## Пример: клиенты с большой суммой заказов

Есть таблица `orders`:

|id|customer_id|amount|
|--:|--:|--:|
|1|101|500|
|2|101|700|
|3|102|300|
|4|103|100|
|5|103|150|
|6|104|2000|

Нужно найти клиентов, которые заказали больше чем на 1000.

```sql
SELECT
  customer_id,
  SUM(amount) AS total_amount
FROM orders
GROUP BY customer_id
HAVING SUM(amount) > 1000
ORDER BY total_amount DESC;
```

Результат:

|customer_id|total_amount|
|--:|--:|
|104|2000|
|101|1200|

Здесь `HAVING` проверяет не один заказ, а сумму всех заказов клиента.
