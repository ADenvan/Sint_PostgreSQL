
## Главное

`HAVING` — это фильтр для групп после `GROUP BY`.

Главная разница:

|Оператор|Что фильтрует|Когда работает|
|---|---|---|
|`WHERE`|Отдельные строки|До группировки|
|`HAVING`|Группы|После группировки|

Базовый пример:

```sql
SELECT
  country,
  COUNT(*) AS users_count
FROM users
GROUP BY country
HAVING COUNT(*) > 100;
```

Главные правила:

- `WHERE` используется до `GROUP BY`.
- `HAVING` используется после `GROUP BY`.
- В `WHERE` нельзя писать условия на `COUNT(*)`, `SUM(amount)`, `AVG(rating)` и другие агрегаты.
- В `HAVING` можно фильтровать по агрегатам.
- Если условие не требует агрегата, лучше писать его в `WHERE`.
- `WHERE` и `HAVING` можно использовать вместе.
- `COUNT(*)` считает все строки.
- `COUNT(column)` считает только строки, где `column` не `NULL`.
- Для переносимости не полагайся на алиасы из `SELECT` внутри `HAVING`; лучше повторяй выражение явно.

Если сказать совсем коротко: `WHERE` решает, какие строки попадут в расчёт, а `HAVING` решает, какие группы останутся после расчёта.
