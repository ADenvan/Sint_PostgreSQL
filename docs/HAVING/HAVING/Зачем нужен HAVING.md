
## Зачем нужен HAVING

`GROUP BY` собирает строки в группы.

Агрегатные функции считают итоги внутри этих групп:

- `COUNT(*)` — сколько строк в группе;
- `SUM(amount)` — какая сумма по группе;
- `AVG(rating)` — какое среднее значение;
- `MIN(created_at)` — самое раннее значение;
- `MAX(created_at)` — самое позднее значение.

А `HAVING` отбирает только те группы, которые подходят под условие.

Например:

- показать только страны, где больше 100 пользователей;
- показать только клиентов, у которых больше 10 заказов;
- показать только товары со средней оценкой выше 4;
- показать только категории, где суммарная выручка больше 50000;
- показать только авторов, у которых опубликовано минимум 5 статей.

То есть `HAVING` — это не фильтр отдельных строк. Это фильтр итогов.
