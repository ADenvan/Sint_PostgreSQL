
## Условия без агрегатов лучше писать в WHERE

Технически в `HAVING` можно писать условия не только на агрегаты, но и на колонки из `GROUP BY`.

Например:

```sql
SELECT
  country,
  COUNT(*) AS users_count
FROM users
GROUP BY country
HAVING country = 'RU';
```

Такой запрос может работать, потому что `country` есть в группировке.

Но лучше написать так:

```sql
SELECT
  country,
  COUNT(*) AS users_count
FROM users
WHERE country = 'RU'
GROUP BY country;
```

Почему второй вариант лучше?

Потому что `WHERE` отфильтрует строки раньше. Базе не придётся группировать пользователей из всех стран, чтобы потом оставить только одну страну.

Простое правило:

> Если условие можно написать в `WHERE`, пиши его в `WHERE`.  
> `HAVING` оставляй для условий на агрегаты.
