
## WHERE и HAVING: главное отличие

Это самая важная часть темы.

`WHERE` фильтрует строки до группировки.

`HAVING` фильтрует группы после группировки.

Посмотрим на два похожих запроса.

Первый запрос:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count
FROM orders
WHERE amount > 50
GROUP BY customer_id;
```

Что делает `WHERE amount > 50`?

Он сначала убирает все заказы на сумму `50` или меньше. И только потом оставшиеся заказы группируются по клиентам.

То есть это вопрос:

> Сколько у каждого клиента заказов дороже 50?

Второй запрос:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count
FROM orders
GROUP BY customer_id
HAVING COUNT(*) > 5;
```

Что делает `HAVING COUNT(*) > 5`?

Он сначала группирует заказы по клиентам, считает количество заказов у каждого клиента, а потом оставляет только тех клиентов, у кого заказов больше 5.

То есть это вопрос:

> Какие клиенты сделали больше 5 заказов?
