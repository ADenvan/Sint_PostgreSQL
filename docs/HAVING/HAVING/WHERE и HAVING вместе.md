
## WHERE и HAVING вместе

`WHERE` и `HAVING` часто используют в одном запросе. Это нормально.

Например, нужно найти клиентов, у которых минимум 3 дорогих заказа.

Дорогой заказ — это заказ дороже 50.

```sql
SELECT
  customer_id,
  COUNT(*) AS big_orders_count
FROM orders
WHERE amount > 50
GROUP BY customer_id
HAVING COUNT(*) >= 3
ORDER BY big_orders_count DESC;
```

Разберём по шагам:

1. `WHERE amount > 50` оставляет только дорогие заказы.
2. `GROUP BY customer_id` группирует эти заказы по клиентам.
3. `COUNT(*)` считает дорогие заказы каждого клиента.
4. `HAVING COUNT(*) >= 3` оставляет только клиентов, у которых таких заказов минимум 3.
5. `ORDER BY big_orders_count DESC` сортирует результат от большего количества к меньшему.

Именно так обычно пишутся нормальные аналитические запросы: сначала убираем лишние строки, потом считаем итоги, потом фильтруем итоги.
