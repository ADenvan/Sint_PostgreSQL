
## HAVING с несколькими агрегатами

В реальных отчётах часто одного условия мало.

Например, нужно найти клиентов, которые:

- сделали минимум 3 заказа;
- потратили суммарно больше 1000;
- имеют средний чек не меньше 300.

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count,
  SUM(amount) AS total_amount,
  AVG(amount) AS avg_amount
FROM orders
GROUP BY customer_id
HAVING COUNT(*) >= 3
   AND SUM(amount) > 1000
   AND AVG(amount) >= 300
ORDER BY total_amount DESC;
```

Такой запрос уже похож на бизнес-логику:

> Покажи нам ценных клиентов, которые покупают не один раз, тратят достаточно много и имеют хороший средний чек.

`HAVING` здесь работает как сито: через него проходят только группы, которые соответствуют всем условиям.
