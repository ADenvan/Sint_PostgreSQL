
## Простая идея на примере

Допустим, есть таблица `orders`:

|id|customer_id|amount|
|--:|--:|--:|
|1|1|100|
|2|1|50|
|3|1|200|
|4|2|80|
|5|3|30|
|6|3|70|

Каждая строка — отдельный заказ.

Сначала посчитаем статистику по каждому клиенту:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count,
  SUM(amount) AS total_amount
FROM orders
GROUP BY customer_id;
```

Результат:

|customer_id|orders_count|total_amount|
|--:|--:|--:|
|1|3|350|
|2|1|80|
|3|2|100|

Теперь задача: оставить только клиентов, у которых сумма заказов больше 150.

Это условие нельзя нормально проверить до группировки, потому что сумма появляется только после `SUM(amount)`.

Поэтому добавляем `HAVING`:

```sql
SELECT
  customer_id,
  COUNT(*) AS orders_count,
  SUM(amount) AS total_amount
FROM orders
GROUP BY customer_id
HAVING SUM(amount) > 150;
```

Результат:

|customer_id|orders_count|total_amount|
|--:|--:|--:|
|1|3|350|

Клиент `1` остался, потому что его сумма заказов `350`.

Клиенты `2` и `3` отсеялись, потому что у них суммы `80` и `100`.
