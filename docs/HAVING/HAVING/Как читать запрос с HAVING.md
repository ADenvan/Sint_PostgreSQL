
## Как читать запрос с HAVING

Возьмём запрос:

```sql
SELECT
  category,
  COUNT(*) AS products_count,
  AVG(price) AS avg_price
FROM products
WHERE is_active = true
GROUP BY category
HAVING COUNT(*) >= 5
   AND AVG(price) > 1000
ORDER BY avg_price DESC;
```

Читать его лучше не сверху вниз, а по смыслу:

1. Берём товары из `products`.
2. Оставляем только активные товары.
3. Группируем их по категории.
4. Для каждой категории считаем количество товаров и среднюю цену.
5. Оставляем только категории, где минимум 5 товаров.
6. Среди них оставляем только категории со средней ценой выше 1000.
7. Сортируем по средней цене от большей к меньшей.

Такой способ чтения помогает не путаться в длинных запросах.
