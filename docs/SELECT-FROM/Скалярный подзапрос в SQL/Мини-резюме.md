
## Мини-резюме

Скалярный подзапрос — это `SELECT`, который возвращает ровно одно значение: одну строку и одну колонку.

Его удобно использовать там, где SQL ждёт обычное значение:

- в `SELECT`, чтобы добавить вычисленную колонку;
- в `WHERE`, чтобы сравнить с результатом другого запроса;
- в `UPDATE`, чтобы записать вычисленное значение в таблицу.

Главная опасность — случайно вернуть несколько строк. Тогда база выдаст ошибку, потому что не сможет выбрать одно значение из нескольких.

Если значений может быть много, используй агрегат, `ORDER BY` с `LIMIT 1`, `IN`, `EXISTS` или `JOIN` — в зависимости от задачи.

И запомни простую мысль: скалярный подзапрос — это маленький запрос, который приносит в большую SQL-картину одну аккуратную деталь.
