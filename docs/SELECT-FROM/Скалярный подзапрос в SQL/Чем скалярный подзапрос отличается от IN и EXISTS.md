
## Чем скалярный подзапрос отличается от IN и EXISTS

Подзапросы бывают разными. Главное отличие — **что именно они возвращают**.

|Вид подзапроса|Что возвращает|Где обычно используется|
|---|--:|---|
|Скалярный подзапрос|Одно значение|В `SELECT`, `WHERE`, `SET`|
|Подзапрос с `IN`|Список значений|В условии `WHERE column IN (...)`|
|Подзапрос с `EXISTS`|Ответ «есть строки или нет»|В условии `WHERE EXISTS (...)`|

Скалярный подзапрос нужен, когда тебе нужно одно значение.

Например:

```sql
SELECT *
FROM orders
WHERE amount > (
  SELECT AVG(amount)
  FROM orders
);
```

А `IN` нужен, когда значений может быть много:

```sql
SELECT *
FROM orders
WHERE customer_id IN (
  SELECT id
  FROM customers
  WHERE city = 'Moscow'
);
```

А `EXISTS` нужен, когда важен сам факт существования строк:

```sql
SELECT *
FROM customers c
WHERE EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.customer_id = c.id
);
```

То есть вопрос не в том, «какой подзапрос лучше», а в том, какую задачу ты решаешь.

Если нужно одно значение — скалярный подзапрос.

Если нужен список — `IN`.

Если нужно проверить наличие — `EXISTS`.
