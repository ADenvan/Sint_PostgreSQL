
## Где можно использовать скалярный подзапрос

Скалярный подзапрос можно поставить почти в любое место, где SQL ждёт **одно значение**.

Чаще всего его используют:

- в `SELECT`, чтобы добавить к строке вычисленное значение;
- в `WHERE`, чтобы сравнить строку с результатом другого запроса;
- в `UPDATE`, чтобы обновить колонку значением из другого запроса.

Например:

```sql
SELECT
  id,
  name,
  (SELECT AVG(amount) FROM orders) AS avg_order_amount
FROM customers;
```

Внутренний запрос считает среднюю сумму заказа. Наружный запрос показывает клиентов и рядом с каждым клиентом выводит это среднее значение.

Важно: подзапрос внутри круглых скобок должен вернуть **одно значение**. Не таблицу, не список, не две колонки — именно одно значение.
