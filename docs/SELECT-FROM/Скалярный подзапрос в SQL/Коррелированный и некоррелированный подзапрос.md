
## Коррелированный и некоррелированный подзапрос

Здесь важно понять одну вещь.

Подзапрос может быть **независимым** или **связанным с наружным запросом**.

Вот независимый подзапрос:

```sql
SELECT *
FROM orders
WHERE amount > (
  SELECT AVG(amount)
  FROM orders
);
```

Внутренний запрос не зависит от текущей строки наружного запроса. Он просто считает среднюю сумму заказа по всей таблице.

Такой подзапрос можно выполнить один раз, получить значение и потом сравнивать с ним каждую строку.

А вот связанный подзапрос:

```sql
SELECT
  c.id,
  c.name,
  (
    SELECT SUM(o.amount)
    FROM orders o
    WHERE o.customer_id = c.id
  ) AS total_spent
FROM customers c;
```

Внутри есть ссылка на `c.id` из наружного запроса. Значит, для каждого клиента значение будет своё.

Такой подзапрос называют **коррелированным**. Он как будто привязан ниточкой к каждой строке внешней таблицы.
