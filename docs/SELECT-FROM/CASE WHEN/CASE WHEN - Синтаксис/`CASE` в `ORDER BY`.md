
## `CASE` в `ORDER BY`

`CASE` можно использовать не только в `SELECT`.

Например, нужно отсортировать заказы не по алфавиту статуса, а по бизнес-приоритету:

1. Сначала оплаченные.
2. Потом ожидающие.
3. Потом все остальные.

```sql
SELECT
  id,
  status,
  created_at
FROM orders
ORDER BY
  CASE status
    WHEN 'paid' THEN 1
    WHEN 'pending' THEN 2
    ELSE 3
  END,
  created_at DESC;
```

Здесь `CASE` превращает статус в число для сортировки.

Заказы со статусом `paid` получают 1 и идут первыми.

Заказы со статусом `pending` получают 2 и идут после них.

Остальные получают 3.

А внутри каждой группы заказы сортируются по `created_at` от новых к старым.

Это один из самых красивых сценариев для `CASE`: мы задаём порядок не по значениям в базе, а по смыслу для бизнеса.
