
## Зачем нужен `CASE WHEN`

Без `CASE` пришлось бы делать так:

1. Забрать из базы сырые данные.
2. Передать их в приложение.
3. В коде пройтись по строкам.
4. Там уже решить, кому поставить `gold`, кому `silver`, а кому `bronze`.

Это работает, но часто хуже: приложение получает больше данных, логика размазывается между базой и кодом, отчёты становятся менее прозрачными.

`CASE` позволяет сказать базе:

«Сразу верни данные в том виде, в котором мне нужно их читать».

Например, можно:

- разбить пользователей на группы по возрасту;
- присвоить клиентам уровни по сумме покупок;
- объединить несколько технических статусов в один понятный;
- посчитать разные категории в одном отчёте;
- задать нестандартную сортировку;
- обновить значения по разным правилам.

`CASE` особенно полезен в отчётах. Он превращает сухие числа и статусы в понятные бизнес-категории.
