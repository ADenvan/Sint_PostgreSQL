
## Типы данных в ветках `CASE`

Все ветки `CASE` должны возвращать совместимые типы.
Вот плохой пример:

```sql
SELECT
  CASE
    WHEN amount >= 1000 THEN 'large'
    ELSE 0
  END AS order_size
FROM orders;
```

В одной ветке возвращается текст `large`, в другой — число 0.
База должна привести результат к одному типу. В PostgreSQL такой запрос может закончиться ошибкой, потому что непонятно, как честно совместить текст и число.

Лучше сделать все ветки текстовыми:

```sql
SELECT
  CASE
    WHEN amount >= 1000 THEN 'large'
    ELSE 'small'
  END AS order_size
FROM orders;
```

Или все ветки числовыми:

```sql
SELECT
  CASE
    WHEN amount >= 1000 THEN 1
    ELSE 0
  END AS is_large_order
FROM orders;
```

Главное правило: один `CASE` — один понятный тип результата.
Если это текстовая категория, пусть все ветки возвращают текст.
Если это числовой флаг, пусть все ветки возвращают числа.
Если это дата, пусть все ветки возвращают даты.
