
##  Главное

`CASE WHEN` — это условная логика внутри SQL-запроса. Он позволяет вернуть разные значения в зависимости от данных в строке.

Самая частая форма:

```sql
CASE
  WHEN condition THEN result
  ELSE default_result
END
```

`CASE` проверяет условия сверху вниз и возвращает результат первого истинного условия.
Если `ELSE` не указан и ни одно условие не подошло, результатом будет `NULL`.
Есть две формы:

- searched `CASE` — для условий, диапазонов и сложной логики;
- simple `CASE` — для сравнения одной колонки с набором значений.

`CASE` можно использовать в `SELECT`, `ORDER BY`, `WHERE`, `UPDATE`, агрегатах и группировках.

Для условного подсчёта часто используют связку `SUM(CASE WHEN ... THEN 1 ELSE 0 END)`. В PostgreSQL для этого также есть удобный синтаксис `FILTER`.

Все ветки `CASE` должны возвращать совместимые типы: текст с текстом, числа с числами, даты с датами.
Для проверки `NULL` нужно писать `IS NULL` или `IS NOT NULL`, а не `= NULL`.

Главная польза `CASE` в том, что он позволяет превратить сырые данные в понятные категории прямо внутри SQL. Благодаря этому запросы становятся не просто способом достать строки из таблицы, а инструментом для аккуратных отчётов, бизнес-логики и понятной аналитики.
