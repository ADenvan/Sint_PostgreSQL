# Что такое SELECT … FROM в SQL?

SELECT — главная команда SQL. С неё начинается любой запрос. Разбираем синтаксис, выбор отдельных колонок, алиасы, вычисляемые поля, частые ошибки и три практических задачи.

Но `WHERE` — это уже следующий слой. Сначала важно уверенно понять базу: `SELECT` выбирает столбцы, `FROM` выбирает таблицу.

Важно: `SELECT` **не меняет данные**. Он только читает.
# Важная мысль: `SELECT` выбирает колонки, а не строки
На первом шаге новичку полезно разделить две идеи:

- `SELECT` отвечает за то, **какие колонки показать**;
- `FROM` отвечает за то, **из какой таблицы взять данные**.

А вот какие строки оставить — это уже задача `WHERE`.

---
## Зачем нужен SELECT
База данных хранит данные в таблицах: пользователи, товары, заказы, посты, платежи, уроки, комментарии — всё это обычно лежит в таблицах.

Но сами по себе данные в таблицах как книги на полке. Чтобы что-то с ними сделать, сначала нужно открыть нужную книгу и прочитать нужные страницы.

Для этого и нужен `SELECT`.

Он позволяет:
- посмотреть данные в таблице;
- выбрать только нужные колонки;
- посчитать значения на лету;
- подготовить данные для отчёта, API или интерфейса;
- проверить, что лежит в базе перед изменениями.

# SELECT + GROUP BY
- [[Главное правило SELECT при GROUP BY]] - Когда в запросе есть `GROUP BY`, в `SELECT` можно указывать только:
	1. колонки, которые есть в `GROUP BY`;
	2. агрегатные функции.
	- Потому что `country` есть в `GROUP BY`, а `COUNT(*)` — агрегатная функция.
- [[GROUP BY и DISTINCT]] - `GROUP BY` иногда путают с `DISTINCT`, потому что оба могут убрать повторяющиеся значения. `DISTINCT` нужен, когда ты хочешь получить список уникальных значений.

# Мини-резюме

`SELECT … FROM` — основа SQL-запросов на чтение.

`SELECT` говорит, какие колонки или выражения нужно показать. `FROM` говорит, из какой таблицы брать данные.

В `SELECT` можно указывать:

- обычные колонки;
- вычисления;
- функции;
- строки и числа;
- алиасы через `AS`;
- `*`, если нужно временно посмотреть все колонки;
- `DISTINCT`, если нужно убрать дубликаты.

`SELECT` ничего не меняет в базе. Он просто читает данные и показывает результат.

Главная мысль для новичка: SQL-запрос можно читать почти как обычную фразу.  
`SELECT name FROM users` — «покажи имена из таблицы пользователей».  
А дальше к этой простой фразе постепенно добавляются фильтры, сортировки, группировки и вся сила SQL.
