
Важно: `SELECT` **не меняет данные**. Он только читает. `SELECT` говорит, какие колонки или выражения нужно показать. `FROM` говорит, из какой таблицы брать данные.
- [[В SELECT можно писать не только колонки]] - В `SELECT` можно указывать не только готовые колонки из таблицы, но и выражения.
- [[DISTINCT как убрать дубликаты]] - Иногда нужно получить не все строки, а только уникальные значения.
- [COUNT(+), COUNT(column) и COUNT(DISTINCT column)](app://obsidian.md/COUNT\(+\),%20COUNT\(column\)%20%D0%B8%20COUNT\(DISTINCT%20column\)) - У `COUNT` есть несколько важных форм.
	- `COUNT(*)` не смотрит, заполнены ли отдельные колонки. Ему важно только количество строк.
	- `COUNT(column)` считает только заполненные значения. Такой запрос посчитает только строки, где `email` не равен `NULL`.
	- `COUNT(DISTINCT column)` считает уникальные значения. Если нужно посчитать не все значения, а только разные, используют `DISTINCT`.
