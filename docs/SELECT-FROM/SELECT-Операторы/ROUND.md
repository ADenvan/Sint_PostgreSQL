
## Пример: товары в интернет-магазине

Есть таблица `products`.

|id|name|price|weight_kg|
|--:|---|--:|--:|
|1|iPhone 15|90000|0.17|
|2|Чайник Bosch|4500|1.20|
|3|Книга «Чистый код»|2000|0.65|

Выведем название товара, цену в рублях и примерную цену в долларах по курсу `90`.

```sql
SELECT
  name,
  price AS price_rub,
  ROUND(price / 90.0, 2) AS price_usd
FROM products;
```

Результат:

|name|price_rub|price_usd|
|---|--:|--:|
|iPhone 15|90000|1000.00|
|Чайник Bosch|4500|50.00|
|Книга «Чистый код»|2000|22.22|

Что произошло?

База взяла `price`, разделила на `90.0`, округлила до двух знаков и вывела как `price_usd`.

В самой таблице новой колонки не появилось. Это просто расчёт в момент чтения.
