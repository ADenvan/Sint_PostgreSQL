
В `SELECT` можно выводить не только колонки и выражения, но и обычные константы.

```sql
SELECT
  name,
  email,
  'active' AS user_status
FROM users;
```
Результат будет содержать колонку `user_status`, где в каждой строке написано одно и то же значение.

Зачем это нужно?

Например, ты готовишь данные для отчёта или объединяешь несколько выборок и хочешь явно подписать источник данных.
```sql
SELECT
  id,
  name,
  'customer' AS entity_type
FROM customers;
```

Колонки `entity_type` нет в таблице. Мы просто добавили её в результат.
