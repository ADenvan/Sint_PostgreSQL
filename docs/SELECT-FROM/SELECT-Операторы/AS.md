
# Алиасы: как переименовать колонку в результате

Иногда название колонки в базе удобное для разработчика, но не очень красивое для отчёта.

Например, в таблице колонка называется `created_at`. Для базы это нормально. Но в отчёте хочется видеть более понятное имя вроде `published_date`.

Для этого используют `AS`.

```sql
SELECT
  title AS post_title,
  likes AS likes_count,
  created_at AS published_date
FROM posts;
```
