
- [[Константы в SELECT]] - Константы `'active' AS user_status`
- [[Строки тоже можно склеивать]] - строки можно склеивать оператором `||`.
- [[AS]] - переименовать колонку в результате `AS`
- [[ROUND]] - Округление 
- [[CONCAT() + CONCAT_WS() + NULLIF()]] - `CONCAT_WS` игнорирует только `NULL`. Если в базе в поле `middle_nm` лежит не `NULL`, а **пустая строка** `''`, функция всё равно добавит лишний дефис. 
	- используем функцию **`NULLIF()`**, которая превращает пустую строку в `NULL`.
