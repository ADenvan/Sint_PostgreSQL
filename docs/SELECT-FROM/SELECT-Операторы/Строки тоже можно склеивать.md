
В запросах часто нужно собрать красивое значение из нескольких колонок.

Например, есть таблица сотрудников.

|id|first_name|last_name|department|salary|
|--:|---|---|---|--:|
|1|Anna|Ivanova|IT|120000|
|2|Boris|Petrov|Sales|80000|
|3|Vera|Sidorova|IT|150000|
|4|Grigory|Nikiforov|HR|70000|

Хотим вывести полное имя, отдел и зарплату с премией 20%.

В PostgreSQL строки можно склеивать оператором `||`.

```sql
SELECT
  first_name || ' ' || last_name AS full_name,
  department,
  salary,
  ROUND(salary * 1.2, 0) AS salary_with_bonus
FROM employees;
```

Результат:

|full_name|department|salary|salary_with_bonus|
|---|---|--:|--:|
|Anna Ivanova|IT|120000|144000|
|Boris Petrov|Sales|80000|96000|
|Vera Sidorova|IT|150000|180000|
|Grigory Nikiforov|HR|70000|84000|

Здесь сразу несколько полезных вещей:

- `first_name || ' ' || last_name` собрал полное имя;
- `salary * 1.2` посчитал зарплату с премией;
- `ROUND` округлил результат;
- `AS` дал красивое имя вычисленной колонке.

В MySQL для склеивания строк обычно используют функцию `CONCAT`.

```sql
SELECT
  CONCAT(first_name, ' ', last_name) AS full_name,
  department,
  salary,
  ROUND(salary * 1.2, 0) AS salary_with_bonus
FROM employees;
```

Смысл тот же, отличается только синтаксис.

## || + CASE  
Иногда в старых базах или специфических задачах `CONCAT_WS` недоступен. Тогда используют оператор `||` и `CASE`:
```sql
SELECT
    last_nm || ' - ' || first_nm || CASE
        WHEN middle_nm IS NOT NULL AND middle_nm != '' THEN ' - ' || middle_nm
        ELSE ''
    END AS fio,
    birth_dt
FROM employees
WHERE is_active = true
ORDER BY last_nm ASC;
```
