## Скобки в сложных условиях

Когда в одном условии есть и `AND`, и `OR`, лучше ставить скобки.

Вот пример:

```sql
SELECT id, name, country, age, tier
FROM users
WHERE country = 'Russia'
  AND (tier = 'gold' OR age >= 30);
```

Читается так:

> Верни пользователей из `Russia`, у которых тариф `gold` или возраст 30+.

Скобки помогают человеку сразу увидеть логику.

Без скобок SQL тоже умеет вычислять выражения по приоритетам: `AND` выполняется раньше, чем `OR`. Но новичку легко ошибиться и получить не тот результат.

Лучше писать явно:

```sql
WHERE country = 'Russia'
  AND (tier = 'gold' OR age >= 30)
```

чем надеяться, что и ты, и база поняли условие одинаково.
