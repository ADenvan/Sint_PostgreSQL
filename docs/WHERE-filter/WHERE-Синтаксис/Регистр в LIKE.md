
## Регистр в LIKE

Во многих базах сравнение строк зависит от регистра.

Например:

```sql
SELECT id, name
FROM users
WHERE name LIKE 'a%';
```

может найти `alice`, но не найти `Alice`.

Если нужен поиск без учёта регистра, есть несколько вариантов.

В PostgreSQL можно использовать `ILIKE`:

```sql
SELECT id, name
FROM users
WHERE name ILIKE 'a%';
```

А более универсальный вариант — привести обе стороны к одному регистру:

```sql
SELECT id, name
FROM users
WHERE LOWER(name) LIKE 'a%';
```

Но у функций в `WHERE` есть нюанс: они могут мешать обычным индексам. На маленьких таблицах это не страшно, на больших стоит подумать об индексах и устройстве поиска.
