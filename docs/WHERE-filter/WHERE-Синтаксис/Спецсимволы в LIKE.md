
## Спецсимволы в LIKE

У `LIKE` есть два основных спецсимвола.

|Символ|Значение|
|---|---|
|`%`|любое количество любых символов|
|`_`|ровно один любой символ|

Пример с `_`:

```sql
SELECT code
FROM products
WHERE code LIKE 'A_1';
```

Такой шаблон подойдёт для:

|code|
|---|
|AA1|
|AB1|
|A91|

Но не подойдёт для:

|code|
|---|
|A100|
|A1|
|B11|

Потому что `_` — это ровно один символ.
