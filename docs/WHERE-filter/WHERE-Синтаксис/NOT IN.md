
## NOT IN: значение не входит в список

Есть обратная форма — `NOT IN`.

```sql
SELECT id, name, country
FROM users
WHERE country NOT IN ('USA', 'Canada');
```

Такой запрос вернёт пользователей, у которых страна не `USA` и не `Canada`.

Но с `NOT IN` нужно быть внимательным, если внутри списка или подзапроса может появиться `NULL`. `NULL` в SQL ведёт себя особенным образом, и результат может оказаться неожиданным.

Для обычного явного списка без `NULL` всё просто:

```sql
WHERE status NOT IN ('cancelled', 'failed')
```

Это значит: статус не должен быть ни `cancelled`, ни `failed`.
