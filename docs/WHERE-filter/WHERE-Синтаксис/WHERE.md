
`WHERE` — это фильтр для строк.

Без `WHERE` запрос берёт всё подряд из таблицы.  
С `WHERE` — только те строки, которые подходят под условие.

Представь таблицу как большой шкаф с вещами. Запрос без фильтра — это «достань весь шкаф на пол». А запрос с `WHERE` — «достань только красные футболки размера L». SQL не тащит лишнее, а сразу отбирает нужное.

Простой пример:
```sql
SELECT name, age
FROM users
WHERE age >= 18;
```

Такой запрос читает таблицу `users`, но возвращает не всех пользователей, а только тех, кому 18 лет или больше.

## Как WHERE работает внутри запроса

Когда база видит запрос с `WHERE`, она проверяет условие для каждой строки.

Например:

```sql
SELECT name, age
FROM users
WHERE age > 18;
```

База рассуждает примерно так:

1. Берёт первую строку.
2. Смотрит значение `age`.
3. Проверяет условие `age > 18`.
4. Если условие истинно — строка попадает в результат.
5. Если условие ложно — строка отбрасывается.
6. Переходит к следующей строке.

То есть `WHERE` — это проверка «подходит строка или нет».

Важно: `WHERE` фильтрует **строки**, а `SELECT` выбирает **колонки**.

```sql
SELECT name, age
FROM users
WHERE age > 18;
```

Здесь:

- `SELECT name, age` говорит, какие колонки показать;
- `FROM users` говорит, из какой таблицы брать данные;
- `WHERE age > 18` говорит, какие строки оставить.
