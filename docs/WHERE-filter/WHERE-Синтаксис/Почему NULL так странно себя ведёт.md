
## Почему NULL так странно себя ведёт

На бытовом уровне `NULL` можно понимать как «неизвестно».

Если значение неизвестно, то сравнение тоже становится неизвестным.

Например:

```sql
WHERE deleted_at = NULL
```

База не думает: «ага, оба значения пустые, значит равно».  
Она думает: «значение неизвестно, сравнение тоже неизвестно».

А `WHERE` пропускает только те строки, где условие стало `TRUE`.

Если результат условия `FALSE` или `UNKNOWN`, строка не попадает в выдачу.

Поэтому проверка на `NULL` вынесена в отдельные операторы.
