
## OR: когда достаточно одного условия

`OR` означает «или».

Строка попадёт в результат, если истинно **хотя бы одно условие**.

Возьмём ту же таблицу:

|id|name|country|age|
|--:|---|---|--:|
|1|Anna|Russia|25|
|2|Bob|USA|30|
|3|Vera|Russia|17|
|4|Grigory|Russia|40|

Запрос:
```sql
SELECT name
FROM users
WHERE country = 'Russia' OR age >= 21;
```

Результат:

|name|
|---|
|Anna|
|Bob|
|Vera|
|Grigory|

Теперь попали все:

- `Anna` подходит по обоим условиям;
- `Bob` подходит по возрасту;
- `Vera` подходит по стране;
- `Grigory` подходит по обоим условиям.

`OR` шире, чем `AND`. Он пропускает больше строк.
