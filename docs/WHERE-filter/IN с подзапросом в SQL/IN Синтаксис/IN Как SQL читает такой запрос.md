
## Как SQL читает такой запрос

Запрос:

```sql
SELECT *
FROM orders
WHERE customer_id IN (
  SELECT id
  FROM customers
  WHERE tier = 'gold'
);
```

Можно мысленно прочитать так:

1. Найди всех клиентов с тарифом `gold`.
2. Возьми их `id`.
3. В таблице `orders` оставь только те заказы, где `customer_id` входит в этот список.

То есть подзапрос превращается в динамический список.

Условно это похоже на такой запрос:

```sql
SELECT *
FROM orders
WHERE customer_id IN (1, 3);
```

Только значения `1` и `3` мы не писали руками. Их нашла база.
