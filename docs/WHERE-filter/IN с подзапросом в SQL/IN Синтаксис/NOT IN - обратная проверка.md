
## NOT IN: обратная проверка
У `IN` есть обратный вариант — `NOT IN`.
`IN` означает:
> Значение есть в списке.
`NOT IN` означает:
> Значения нет в списке.

Например, нужно выбрать заказы не `gold`-клиентов:

```sql
SELECT *
FROM orders
WHERE customer_id NOT IN (
  SELECT id
  FROM customers
  WHERE tier = 'gold'
);
```


Если подзапрос вернул список `1` и `3`, то внешний запрос оставит заказы клиентов, чей `customer_id` не равен ни `1`, ни `3`.

На наших данных результат будет таким:

|id|customer_id|amount|
|--:|--:|--:|
|2|2|50|
Клиент `2` не `gold`, поэтому его заказ остался.
Но у `NOT IN` есть очень опасная ловушка.
