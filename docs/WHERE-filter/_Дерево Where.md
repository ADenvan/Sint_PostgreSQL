
# Что такое WHERE в SQL?

`WHERE` — фильтр строк в `SQL`. Простыми словами и на пальцах: =, IN, BETWEEN, LIKE, IS NULL и AND/OR. Куча примеров с таблицами «до и после», частые ошибки новичков и мини-практика в конце.

`WHERE` — это фильтр для строк.

Без `WHERE` запрос берёт всё подряд из таблицы.  
С `WHERE` — только те строки, которые подходят под условие.

Представь таблицу как большой шкаф с вещами. Запрос без фильтра — это «достань весь шкаф на пол». А запрос с `WHERE` — «достань только красные футболки размера L». SQL не тащит лишнее, а сразу отбирает нужное.

---
## Зачем нужен WHERE

В учебной таблице может быть 5 строк. В настоящей базе — тысячи, миллионы или десятки миллионов.

Если каждый раз доставать всю таблицу целиком, будет плохо:

- база сделает лишнюю работу;
- приложение получит слишком много данных;
- запрос станет медленнее;
- нужную информацию будет сложнее найти;
- можно случайно показать пользователю не те данные.

`WHERE` решает эту проблему. Он отсекает лишние строки прямо на стороне базы данных.

# HAVING + WHERE
- [[WHERE и HAVING - в чём разница]] - 
	- `WHERE` и `HAVING` оба фильтруют данные, но делают это в разные моменты.
	- `WHERE` фильтрует строки до группировки.
	- `HAVING` фильтрует группы после группировки.
- [[WHERE и HAVING - главное отличие]] - Это самая важная часть темы.
	- `WHERE` фильтрует строки до группировки.
	- `HAVING` фильтрует группы после группировки.
- [[WHERE и HAVING вместе]] - `WHERE` и `HAVING` часто используют в одном запросе. Это нормально.
	1. `WHERE amount > 50` оставляет только дорогие заказы.
	2. `GROUP BY customer_id` группирует эти заказы по клиентам.
	3. `COUNT(*)` считает дорогие заказы каждого клиента.
	4. `HAVING COUNT(*) >= 3` оставляет только клиентов, у которых таких заказов минимум 3.
	5. `ORDER BY big_orders_count DESC` сортирует результат от большего количества к меньшему.
