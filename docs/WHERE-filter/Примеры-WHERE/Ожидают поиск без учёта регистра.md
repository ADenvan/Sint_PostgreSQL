
### Ожидают поиск без учёта регистра

В большинстве случаев строки с разным регистром могут считаться разными.

```sql
SELECT id, name
FROM users
WHERE name = 'alice';
```

Такой запрос может не найти `Alice`.

Если регистр не важен, можно привести обе стороны к нижнему регистру:

```sql
SELECT id, name
FROM users
WHERE LOWER(name) = LOWER('Alice');
```

В PostgreSQL для шаблонов также есть `ILIKE`.

```sql
SELECT id, name
FROM users
WHERE name ILIKE 'a%';
```
