### Не ставят скобки в сложной логике

Плохо читается:

```sql
SELECT id, name
FROM users
WHERE country = 'Russia' AND tier = 'gold' OR age >= 30;
```

Лучше явно:

```sql
SELECT id, name
FROM users
WHERE (country = 'Russia' AND tier = 'gold')
   OR age >= 30;
```

Или так, если смысл другой:

```sql
SELECT id, name
FROM users
WHERE country = 'Russia'
  AND (tier = 'gold' OR age >= 30);
```

Скобки показывают намерение. Это особенно важно в рабочих запросах.
