
## Полезная привычка: читать WHERE как обычную фразу

SQL легче изучать, если читать условия по-человечески.

```sql
SELECT id, amount
FROM orders
WHERE status = 'paid'
  AND amount > 1000;
```

Это можно прочитать так:

> Покажи `id` и `amount` из заказов, где статус оплачен и сумма больше 1000.

А вот так:

```sql
SELECT id, email
FROM users
WHERE email LIKE '%@gmail.com'
  AND deleted_at IS NULL;
```

читается как:

> Покажи пользователей с Gmail-почтой, которые не удалены.

Если условие сложно прочитать вслух, часто его стоит переписать аккуратнее: добавить переносы строк, скобки или разбить задачу на несколько шагов.
