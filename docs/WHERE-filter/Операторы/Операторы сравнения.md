
## Операторы сравнения

В `WHERE` часто используют обычные сравнения.

|Оператор|Значение|
|---|---|
|`=`|равно|
|`<>`|не равно|
|`!=`|не равно, поддерживается во многих СУБД|
|`>`|больше|
|`<`|меньше|
|`>=`|больше или равно|
|`<=`|меньше или равно|

Примеры:

```sql
SELECT name, price
FROM products
WHERE price = 1200;
```

```sql
SELECT name, price
FROM products
WHERE price <> 1200;
```

```sql
SELECT name, price
FROM products
WHERE price <= 1000;
```

Со строками сравнение тоже работает:

```sql
SELECT id, name, country
FROM users
WHERE country = 'Russia';
```

Строковые значения пишутся в одинарных кавычках.

Числа — без кавычек:

```sql
SELECT id, name, age
FROM users
WHERE age >= 21;
```
