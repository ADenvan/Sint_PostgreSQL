
## NOT EXISTS: обратная проверка

`NOT EXISTS` делает обратное.

Он отвечает на вопрос:

> Не существует ли подходящей строки?

Если подзапрос ничего не нашёл, `NOT EXISTS` возвращает `TRUE`.

Например, найдём клиентов, у которых нет ни одного заказа:

```sql
SELECT *
FROM customers c
WHERE NOT EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.customer_id = c.id
);
```

Результат:

|id|name|
|--:|---|
|2|Bob|
|4|Gleb|

У `Bob` нет заказов.  
У `Gleb` нет заказов.  
Значит, они попали в результат.

А `Anna` и `Vera` не попали, потому что для них связанные строки в `orders` существуют.

## Где используют NOT EXISTS

`NOT EXISTS` часто используют для поиска отсутствующих связей.

Например:

- клиенты без заказов;
- товары без продаж;
- посты без комментариев;
- пользователи без активной подписки;
- категории, в которых нет товаров;
- заказы без платежей;
- записи, которые ещё не были обработаны.

Пример: найти товары, которые ни разу не продавались.

```sql
SELECT *
FROM products p
WHERE NOT EXISTS (
  SELECT 1
  FROM order_items oi
  WHERE oi.product_id = p.id
);
```

Читается так:

> Верни товары, для которых не существует ни одной строки в `order_items`.

Это один из самых чистых способов написать запрос «найди то, чего нет».
