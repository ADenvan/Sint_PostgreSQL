
## EXISTS и условия по нескольким колонкам

`EXISTS` особенно удобен, когда связь определяется не одной колонкой, а несколькими.

Например, есть таблица `subscriptions`, где подписка привязана к пользователю и продукту:

|user_id|product_id|status|
|--:|--:|---|
|1|10|active|
|1|20|cancelled|
|2|10|active|

Нужно найти пользователей, у которых есть активная подписка на конкретный продукт.

```sql
SELECT *
FROM users u
WHERE EXISTS (
  SELECT 1
  FROM subscriptions s
  WHERE s.user_id = u.id
    AND s.product_id = 10
    AND s.status = 'active'
);
```

Внутри `EXISTS` можно спокойно описать все условия:

- совпадает пользователь;
- совпадает продукт;
- статус активный.

С `EXISTS` такие запросы читаются естественно: есть строка, которая удовлетворяет всем условиям, или нет.
