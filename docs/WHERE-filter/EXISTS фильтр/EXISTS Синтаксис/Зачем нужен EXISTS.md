
## Зачем нужен EXISTS

Допустим, у нас есть две таблицы:

- `customers` — клиенты;
- `orders` — заказы.

Нужно получить клиентов, у которых есть хотя бы один заказ.

Можно попробовать сделать через `JOIN`, но тогда клиент с десятью заказами появится в результате десять раз. Потом придётся добавлять `DISTINCT`, чтобы убрать дубликаты.

Можно попробовать через `IN`, но у него есть неприятные особенности, особенно в обратных проверках с `NOT IN` и `NULL`.

А можно использовать `EXISTS`, потому что он как раз создан для таких задач:

> Покажи строки из одной таблицы, если в другой таблице существует связанная строка.

Это читается почти как обычная человеческая мысль.
