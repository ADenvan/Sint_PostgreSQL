
## Главное

`EXISTS` проверяет, вернул ли подзапрос хотя бы одну строку.

Самое важное:

- `EXISTS` возвращает `TRUE`, если подзапрос нашёл хотя бы одну строку;
- `EXISTS` возвращает `FALSE`, если подзапрос не нашёл ничего;
- внутри `EXISTS` принято писать `SELECT 1`, потому что содержимое строки не важно;
- чаще всего `EXISTS` используют в `WHERE`;
- `NOT EXISTS` ищет строки, для которых связанная запись не найдена;
- для задач «нет связанной строки» обычно лучше использовать `NOT EXISTS`, а не `NOT IN`;
- `EXISTS` не дублирует строки внешней таблицы, в отличие от `JOIN`;
- если нужны данные из второй таблицы, используйте `JOIN`;
- если нужно только проверить наличие строки, часто лучше `EXISTS`;
- для хорошей производительности важны индексы на колонках связи;
- не забывайте связывать подзапрос с внешней таблицей, иначе проверка будет относиться ко всей таблице целиком.

Если совсем коротко: `EXISTS` — это SQL-способ сказать базе данных: «Покажи мне строки, для которых в другой таблице что-то нашлось».
