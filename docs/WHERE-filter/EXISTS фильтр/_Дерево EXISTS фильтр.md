
# Что такое EXISTS в SQL?

EXISTS — это «есть ли хотя бы одна строка, удовлетворяющая условию». Простыми словами: фильтр на наличие связанной записи (например «клиенты, у которых есть хотя бы один заказ»), отличие от IN с подзапросом, NOT EXISTS и поведение с NULL.

`EXISTS` в SQL — это проверка на существование.

Она отвечает на простой вопрос:

> Есть ли хотя бы одна строка, которая подходит под условие?

Если такая строка есть, `EXISTS` возвращает `TRUE`.  
Если не нашлось ни одной строки, возвращает `FALSE`.

Чаще всего `EXISTS` используют внутри `WHERE`, когда нужно отфильтровать строки по принципу «у этой записи есть связанная запись в другой таблице».

Например:

- показать клиентов, у которых есть хотя бы один заказ;
- найти товары, у которых есть отзывы;
- выбрать посты, у которых есть комментарии;
- найти пользователей, у которых есть активная подписка;
- наоборот, найти клиентов, у которых нет ни одного заказа.

Главная мысль: `EXISTS` не считает строки и не достаёт данные из подзапроса. Ему важно только одно: **нашлось что-нибудь или нет**.
